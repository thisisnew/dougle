# Dougle 0.1.15

자료 목록의 빈 화면을 **‘자료를 추가해 보세요’** 한 줄로 바꾸고 ‘상단에서 자료를 추가하세요.’라는 반복 안내를 제거했습니다. 기능·DB v23·인증·자료 저장 방식은 변경하지 않습니다.

App 회귀 13건과 TypeScript/Vite 빌드를 통과했습니다. 최종 UI 전체·양 CPU 패키지 검증 및 재설치를 진행합니다. 이전 Java 전체 검사의 기존 종료/임시 폴더 정리 오류는 [0.1.14 보고서](release-0.1.14-report.md)에 기록되어 있으며 이번 문구 변경으로 해결된 것으로 보고하지 않습니다. ARM 실기기·외부 AI·Apple 공증은 별도입니다.
