# Dougle 0.1.14

[자료 화면·설정 간소화](library-simplification.md)를 적용했습니다. 현재 검증·패키징 중이며 공개·로컬 설치 완료를 뜻하지 않습니다.

- 연결 자료/업로드 목록 통합, 루트 중복 제거, 상단 전체 동기화.
- 캐릭터 하단 이동, 짧은 삭제 확인, AI 연결·실행 경로 설명 정리.
- 자동 갱신 정렬, 질문 기록의 새 질문 버튼 제거.
- UI 전체 **257건**, Rust **19건**, TypeScript/Vite/JAR 및 양 CPU 네이티브 빌드를 통과했습니다. 병렬 빌드 중 새 UI 검사 1건이 시간 초과됐고 단독 11건·전체 제한 병렬 257건 재검사를 통과했습니다. 시간 제한이나 앱 동작을 완화하지 않았습니다.
- 실제 브라우저에서 업로드·연결 자료 통합 목록, 전체 동기화(실패 URL 이후 가상 폴더 성공), 내부 파일 탐색, 삭제 취소/확정, 자동 갱신 값 저장, 간결한 AI/경로 설정, 기록 화면의 새 질문 버튼 없음, 가로 넘침 없음을 확인했습니다. 가상 생성 호출 0회. 브라우저에서 OS 폴더 선택은 불가능하므로 폴더 fixture만 로컬 테스트 API로 등록했고 동기화/탐색은 실제 UI로 실행했습니다.
- 네이티브 첫 검사에서는 제거한 ‘아직 확인하지 않음’을 기다리던 예전 검사가 실패했습니다. 제공자 선택·연결 버튼 활성·중복 상태 문구 없음으로 검증을 바꾸고 재검사합니다. 앱/승인/인증 검사를 완화하지 않았습니다.
- Intel 실행·ARM 정적·공개 배포·로컬 재설치는 진행 중입니다.
- 실제 외부 AI 호출·ARM 실기기·Apple 공증은 이번 검증 범위가 아닙니다.
