# 0.1.10 — 기능 다이어트

소스 `4d4558b`의 Intel/Apple Silicon 설치 파일과 서명 업데이트를 [0.1.10 릴리스](https://github.com/thisisnew/knowledge-forge/releases/tag/v0.1.10-preview.1)에 공개했습니다. 자산 10개의 크기·SHA-256을 로컬 파일과 대조했습니다. 이 Mac에도 0.1.10을 설치했습니다. [쉬운 사용법과 코드 대조](simple-workflow.md).

두 DMG 공개 다운로드 HTTP 200을 확인했습니다. 공개 자산의 해시·서명을 다시 검증한 뒤 업데이트 피드를 0.1.10으로 갱신했습니다. GitHub 캐시 때문에 앱의 업데이트 알림에는 지연이 있을 수 있습니다.

- 기본 질문의 내부 검증·승인 상태·작업 조회 버튼을 줄이고 명시적 전송 동의 흐름으로 합쳤습니다.
- 자료 관리·코드 분석·문서 작성/게시·대화 정리 도구를 기본 화면과 분리했습니다. 자료·문서·답변을 삭제하지 않았습니다.
- DB v21, 서버의 전송 직전 재검증·일회 승인·중복 접수 방지·사람 편집 보호·게시 조건은 변경하지 않았습니다.
- 최초 UI 검사 224건 중 변경 전 문구와 삭제 버튼을 기대하던 2건이 실패했습니다. 새 흐름에 맞춰 수정한 뒤 224건, 간편 답변 중단 회귀 추가 후 225건을 통과했습니다. 이후 사용하지 않는 기존 준비 컴포넌트와 그 단위 검사 6건을 제거했으므로 최종 수는 달라집니다. 검사를 중복 합산하지 않습니다.
- 접힌 관리 기능을 DOM에서 삭제했다고 가정한 테스트 1건이 실패했습니다. 실제 요구는 보존한 채 숨기는 것이므로 가시성을 검사하도록 수정했습니다. 파일 목록 감사는 삭제를 Git index에 반영하기 전 실행해 실패했으며 삭제 반영 후 재실행합니다.
- 최종 전체 UI 219건·Java 378건 통과(실제 AI 자동 검사 1건 제외), Rust 17건 통과. TypeScript/Vite·Spring Boot 빌드 성공. Vite의 주 번들 500kB 초과 경고는 남으며 빌드 실패는 아닙니다.
- 브라우저에서 가상 파일 업로드 → 질문 → 인용 확인 → 전송 준비 → 미체크 동의/비활성 전송 확인 → 명시적 동의 → 가상 답변 완료 → 이력 목록 보존을 확인했습니다. 가상 CLI 호출은 1회, 실제 AI 호출은 없습니다. 질문 창 가로 넘침도 없습니다.
- 이력 화면 검사에서 `완료` 대신 `답변 생성 완료`를 기다려 시간 초과가 발생했습니다. 실제 목록에 질문과 완료 상태가 보존된 것을 확인했으며 제품 오류가 아닌 검사 문구 오류입니다.
- 새 자료의 첫 동기화가 접힌 관리 영역에 묻히지 않도록 등록 직후 관리 영역을 펼치고 `가져오기 필요`를 표시하도록 보완했습니다. 변경된 UI 전체 검사·JAR 재포장은 별도로 다시 실행합니다.
- 보완 후 전체 UI 219건과 TypeScript/Vite 빌드·JAR 재포장도 통과했습니다. 브라우저에서 자료 등록 직후 관리 영역 자동 열림 → 명시적 동기화 → 관리 접기를 확인했고 가로 넘침이 없습니다. 이 후속 검사의 가상 AI 호출은 0회입니다.
- JAR 통합 검사 통과. 가상 파일 100개 순차 검색 p95 50.5ms이며 대규모·동시 사용자 성능을 뜻하지 않습니다. [측정](performance-phase3-foundation.json). 최종 JAR에서는 자료 연결 화면만 보완했으며 백엔드 테스트 결과와 중복 합산하지 않습니다.

## 설치 파일

- 2026-10-24 사용자 요청으로 같은 0.1.10 Intel DMG에서 로컬 앱을 다시 설치했습니다. SHA-256·DMG 체크섬·복사본 코드 서명·버전·CPU를 확인했고 기존 앱은 비공개 백업했습니다. 재실행 후 네이티브/Java 프로세스·화면 HTTP 200·미인증 API 403을 확인했습니다. 사용자 자료·인증 폴더는 건드리지 않았습니다. 코드 변경 없는 재설치이므로 설치 파일·업데이트 피드는 그대로 유지합니다.

- Intel DMG 설치 복사본의 실제 WebKit UI·Workspace·파일·검색·게시·자료 설정·AI 연결 검사와 서명을 통과했습니다. 실제 AI 생성 검사는 아닙니다.
- Intel 업데이트 압축의 서명·버전·CPU·현재 JAR 일치를 확인했습니다.
- Applications의 이전 0.1.9 앱을 정상 종료·비공개 백업하고 0.1.10으로 교체·재실행했습니다. 사용자 자료·인증 폴더는 수정하지 않았습니다.
- 실제 설치 앱의 Java 자식 실행·화면 HTTP 200·미인증 API 403을 확인했습니다. 별도 임시 HOME에서 중복 실행 차단·부모 종료 시 Java 종료·같은 DB 재시작 검사도 통과했습니다. 병행 빌드 중 시작 시간 60.6초는 일반 사용 성능으로 해석하지 않습니다. [측정](native-host-report.json).
- ARM DMG의 설치 복사본·CPU·서명 정적 검사와 업데이트 압축의 서명·버전·현재 JAR 일치 검사를 통과했습니다. ARM 실기기 실행·Apple 공증·실제 외부 AI 생성은 이번 검사에 포함하지 않습니다.
