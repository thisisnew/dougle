# Dougle 0.1.13

CLUE를 Dougle · 더글로 변경했습니다. 둥근 다색 글자 로고, 화이트/블루 화면, 중앙 로고와 질문창, “더글한테 물어보기” 안내를 적용합니다. 캐릭터와 자료·인증·업데이트 호환성은 유지합니다. [디자인·구현](dougle-brand.md).

0.1.13 공개 자산 10개의 크기·SHA-256을 대조한 뒤 공개하고 업데이트 피드를 승격했습니다. 0.1.12는 대체된 초안으로 남습니다. 이전 공개 자산은 수정하지 않았습니다.

## 검증 상태

- 최종 화면 전체 회귀 **254건** 통과. 로고 접근성·입력 안내·불필요한 문구 제거·대화/기록 아이콘 구분·연결 전 전송 잠금·실제 전송 승인 절차를 확인했습니다. 아래 후속 개별 검사 수는 중복 합산하지 않습니다.
- ‘내 자료 기반 · 새 질문’을 제거하고 첨부 버튼은 왼쪽, 전송 버튼은 오른쪽에 유지했습니다.
- 하단 ‘자료 전송은 동의 후에만 진행됩니다’ 문구도 제거했습니다. 실제 전송 동의 동작을 포함한 ChatPanel 회귀 12건 통과. 최종 설치본 JAR에도 포함했습니다.
- 사이드바의 ‘최근 질문’ 제목·빈 목록 안내를 없앴습니다. 질문 기록에는 대화 말풍선과 다른 시계 아이콘을 사용합니다. 후속 대화/로고 회귀 13건 통과(중복 합산하지 않음).
- Dock용 다색 Dougle 워드마크 아이콘을 생성하고 1024px 원본을 시각 확인했습니다. 사이드바 캐릭터는 유지합니다.
- Rust **19건**, Intel/ARM 네이티브 빌드를 통과했습니다. 전체 목록 감사는 353개 파일·104개 테스트/fixture 파일이며 실행 커버리지 수치는 아닙니다. 설치본 최종 검증·공개 배포를 완료했습니다.
- 브라우저에서 Workspace 생성·가상 Codex 로그인·질문 기록 카드와 설정 이동을 확인했습니다. 불필요 문구 없음·메뉴 아이콘 구분·가로 넘침 없음도 확인하고 소개 화면 3장을 갱신했습니다. 가상 AI 생성 호출은 0회입니다.
- 양 CPU DMG 정적 검사·서명된 업데이트 압축/버전/JAR 일치 검사가 통과했습니다. Intel 최종 DMG의 실제 React/WebKit Workspace·AI 버튼·한글 오류·자료/검색·승인/설정 검사가 통과했습니다.
- 실행 예제를 직접 호출한 첫 3회는 시스템 PATH의 Claude를 감지해 ‘도구 없음’을 기다리다가 실패했습니다. 진단 단계를 세분화했고, 기존 표준 `verify-macos-package.sh`의 격리 PATH로 최종 통과했습니다. 앱·인증·검사 시간 제한을 완화하지 않았습니다.
- 이 Mac은 기존 앱/닫힌 DB를 백업한 뒤 최종 Intel DMG로 재설치했습니다. 버전 0.1.13·표시 이름 Dougle·ICNS 일치·macOS가 반환한 새 아이콘·화면 HTTP 200·미인증 API 403을 확인했습니다. 사용자 자료 내용/인증은 조회하지 않았고 앱 ID·저장 위치는 보존했습니다. 공개 자산 업로드·피드 승격을 완료했습니다.

실제 외부 AI 호출·ARM 실기기·Apple 공증은 이번 범위에 포함하지 않습니다.
