# 간편 AI 연결 검증 기록

이 문서는 연결 기능 개발 당시의 기록입니다. 디자인을 정돈한 최종 0.1.2 설치 파일과 체크섬은 [새 배포 기록](release-0.1.2-report.md)을 따릅니다. 아래 로컬 설치본 체크섬은 디자인 변경 전의 과거 값입니다.

기준: 2026-10-22, 0.1.2 개발 소스, DB v21. 공개된 0.1.1과 구별합니다.

## 모델과 구현을 어떻게 대조했나?

- 코드·테스트·빌드 설정 305개 파일의 목록/해시를 만들었습니다. 이 중 테스트/fixture 분류는 84개입니다.
- 모든 Java 도메인의 의존성과 application → adapter 역참조, 모든 테이블의 모델 문서 등재를 구조 테스트 3개로 검사했습니다.
- 자료 격리·원본 보존·증분 반영·수동 편집 보호·게시·전송 승인·SSE·문맥 고정 규칙을 실제 코드와 회귀 테스트에 연결했습니다.
- 발견한 차이와 조치는 [대조표](model-audit.md)를 보세요. **전체 파일 조사와 모든 코드 줄의 수동 검증은 다릅니다.**

## 아직 증명하지 않은 것

- 실제 계정의 브라우저 로그인·모델 이용 가능 여부·요금/한도·실제 답변 성공.
- Claude 실행 도구 동봉. 제품 배포 조건 확인이 필요합니다.
- 새 연결 기능의 ARM 실기기 실행. 교차 빌드 성공과 구별합니다.
- 로그인 대기 중 화면 새로고침 복구. 메모리 작업은 최대 3분 뒤 종료합니다.
- GitHub 수집에 필요한 Git의 동봉. 현재 별도 실행 환경에 의존합니다.

## 로컬 설치 산출물

- `release/Knowledge.Forge_0.1.2_x86_64.dmg` 생성 및 설치 복사본 실행 검사 통과. 아직 GitHub Release에 공개하지 않았습니다.
- DMG SHA-256: `1daa4d253ebe085fbc762d0bf5682eada7408286e962b68fef8950d89193597e`.
- 최종 빌드 JAR와 앱에 들어간 JAR의 SHA-256 일치: `cf8dfda118a86b6a0731e12792a4dff92c62a6bbb39ac2ba841368910ef57195`.
- 동봉된 Codex의 `--version`: `codex-cli 0.163.0`. 이 명령은 로그인/모델 호출이 아닙니다.
- 새 ARM 설치본 빌드·정적 검사와 CPU별 공개 배포는 다음 작업입니다. 기존 0.1.1 ARM 공개판은 이 변경 이전입니다.
- 이 설치본 생성 후 요청받은 [2D 디자인](retro-design.md)은 개발 소스에 별도로 추가했으므로 해당 디자인은 설치본에 아직 없습니다.

네이티브 수명주기 추가 검사 첫 실행은 두 번째 Java의 종료 순간 프로세스 이름이 `(java)`로 바뀌어 실패했습니다. 검사기가 이름 일치만으로 대기를 끝내던 부분을 관측한 PID가 없어질 때까지 기다리도록 수정했습니다. 종료 대기 제한 시간과 중복 실행 거부 조건은 유지합니다.
수정 후 격리 HOME·최소 PATH에서 시작·세션 보호·중복 백엔드 거부·종료·재시작 검사를 통과했습니다. 당시 시작 시간은 이 Intel 호스트의 단일 측정(12,023ms)이었습니다. 최신 재측정은 [새 배포 기록](release-0.1.2-report.md)을 따르며 일반 성능 보증이 아닙니다.

Apple 공증은 요청에 따라 제외합니다. 실제 계정 인증과 다른 Mac 설치 검증까지 끝났다는 뜻은 아닙니다.
