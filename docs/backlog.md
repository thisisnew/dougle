## 현재 우선순위 — 2026-10-26

최신 사용자 결정은 **Slack을 포함한 외부 업무 시스템 조회 전용**이다. 앱 내부 저장은 유지하되 외부 쓰기는 승인·설정과 무관하게 거부한다. 기존 답장 전송 검증은 과거 구현의 증거일 뿐 새 정책의 인수가 아니다. 정책 반영 전 설치 파일은 공개·설치하지 않는다.

현재 작업은 실무 전문가 기능과 50개 인수 기준의 연속 구현·검증이다. 아래 2026-10-24의 ‘확장 개발 보류’는 과거 결정이며 현재 요청을 제한하지 않는다. 구현·패키지·설치 상태는 [HANDOFF](../HANDOFF.md), 실제 인수 판정은 [평가 기록](expert-evaluation-status.json)을 우선한다. 단위 검사와 가상 서비스 검사는 실제 계정·다른 Mac 검증을 대신하지 않는다.
