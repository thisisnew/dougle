# 0.1.9 — 검색·질문·문서 화면 정리

현재 구현 후 빌드·검증 중입니다. 공개 설치본과 업데이트 피드는 아직 0.1.8입니다.

최종 통합 빌드: UI 217건, Java 378건 통과(실제 AI 자동 검사 1건 제외), Rust 17건 통과. Intel/ARM 설치본을 순서대로 빌드하며 실제 UI 검사와 배포는 아래 결과가 확인된 뒤 완료 처리합니다.

[쉬운 사용법·구현 대조](ux-0.1.9.md).

- 체크박스의 간격·크기·줄바꿈과 대화상자 공통 간격을 개선했습니다.
- 검색과 AI 질문을 구분하고, 검색 범위·자동 갱신 설정은 펼칠 때 보이게 했습니다.
- `근거 묶음` → `AI에게 질문하기`, `답변 이력` → `이전 답변 보기`로 바꿨습니다. 데이터나 기능은 삭제하지 않습니다.
- 빈 지식 화면의 관리 패널을 숨기고 원본 자료로 시작하는 버튼을 추가했습니다.
- 첫 UI 검사는 변경 전 빈 화면 문구를 기대하던 테스트 1건이 실패했습니다. 새 안내 문구에 맞춰 수정 후 전체 216건을 통과했고 추가 질문 입력 회귀를 포함한 최종 빌드를 진행합니다.
- 추가 질문 입력 검사는 초기 목록 로딩 중 비활성 입력창에 입력하려 해 실패했습니다. 입력 가능 상태를 기다리도록 검사기를 수정했고 집중 33건, 최종 전체 UI 217건을 통과했습니다. Rust 17건도 통과했습니다. 실제 설치 WebKit에서 체크박스 16px·글자와 간격 8px 이상을 검사합니다.
- DB v21·전송 승인·수동 편집/게시 보호·업데이트 키는 그대로입니다.
