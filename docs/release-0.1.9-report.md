# 0.1.9 — 검색·질문·문서 화면 정리

소스 `0050cdd`의 Intel/Apple Silicon 설치 파일과 서명 업데이트를 [0.1.9 릴리스](https://github.com/thisisnew/dougle/releases/tag/v0.1.9-preview.1)에 공개했습니다. 자산 10개의 크기·SHA-256을 로컬과 대조했으며 이 Mac의 설치 앱도 0.1.9로 교체했습니다.

두 DMG 공개 다운로드 HTTP 200을 확인했습니다. 공개 업데이트 자산의 해시·서명 재검증 후 피드를 0.1.9로 갱신합니다. GitHub 캐시에 따라 앱의 새 버전 알림에는 지연이 있을 수 있습니다.

최종 통합 빌드: UI 217건, Java 378건 통과(실제 AI 자동 검사 1건 제외), Rust 17건 통과. Intel 설치 UI/실행, ARM 정적, 두 CPU 서명 검증도 통과했습니다.

[쉬운 사용법·구현 대조](ux-0.1.9.md).

- 체크박스의 간격·크기·줄바꿈과 대화상자 공통 간격을 개선했습니다.
- 검색과 AI 질문을 구분하고, 검색 범위·자동 갱신 설정은 펼칠 때 보이게 했습니다.
- `근거 묶음` → `AI에게 질문하기`, `답변 이력` → `이전 답변 보기`로 바꿨습니다. 데이터나 기능은 삭제하지 않습니다.
- 빈 지식 화면의 관리 패널을 숨기고 원본 자료로 시작하는 버튼을 추가했습니다.
- 첫 UI 검사는 변경 전 빈 화면 문구를 기대하던 테스트 1건이 실패했습니다. 새 안내 문구에 맞춰 수정 후 전체 216건을 통과했고 추가 질문 입력 회귀를 포함한 최종 빌드도 통과했습니다.
- 추가 질문 입력 검사는 초기 목록 로딩 중 비활성 입력창에 입력하려 해 실패했습니다. 입력 가능 상태를 기다리도록 검사기를 수정했고 집중 33건, 최종 전체 UI 217건을 통과했습니다. Rust 17건도 통과했습니다. 실제 설치 WebKit에서 체크박스 16px·글자와 간격 8px 이상을 검사합니다.
- DB v21·전송 승인·수동 편집/게시 보호·업데이트 키는 그대로입니다.

## 브라우저·통합 검사

- 가상 Workspace 생성 → 검색 범위 펼치기 → 빈 지식 문서 → 원본 자료로 이동 → 질문 입력·참고 자료 찾기 → 이전 답변 조회를 실제 화면에서 확인했습니다.
- 900px 창에서 체크박스 16px, 글자와 간격 10px이며 가로 넘침이 없습니다. 질문 창도 내용 폭 829px로 가로 넘침이 없습니다. 빈 작업·폴더 관리 패널은 숨겨집니다.
- 자료가 없을 때 `NO_EVIDENCE`를 표시했습니다. 테스트 서버 종료 시 AI 호출 0회를 확인했습니다. 실제 사용자 자료·인증은 사용하지 않았습니다.
- 최종 JAR 통합 검사 통과. 가상 파일 100개 순차 검색 p95 46.8ms이며 실제 대규모·동시 사용자 성능을 뜻하지 않습니다. [측정 원본](performance-phase3-foundation.json).
- 브라우저 최초 탐색 시간 초과와 잘못된 도구 호출 문법은 같은 테스트 공간에서 복구했습니다. 앱 결함으로 집계하지 않습니다.
- [변경 화면과 사용법](ux-0.1.9.md)에 스크린샷을 첨부했습니다.

## 설치 검사

- Intel DMG 설치 복사본의 WebKit UI 검사를 통과했습니다. 실제 React Workspace·파일·검색·게시·관계·자료 설정·AI 인증 버튼과 체크박스 크기·간격을 검사하며 실제 AI 생성은 하지 않습니다.
- Intel 업데이트 압축의 서명·버전·CPU·현재 JAR 일치 검사를 통과했습니다.
- 이 Mac의 Applications 앱을 정상 종료하고, 이전 0.1.8 앱을 비공개 백업한 뒤 검증한 0.1.9로 교체·재실행했습니다. 사용자 자료 폴더는 수정하지 않았습니다.
- 실제 설치 앱의 버전 0.1.9·Java 자식 실행·화면 HTTP 200·미인증 API 403을 확인했습니다. 별도 임시 HOME에서는 중복 실행 차단·부모 종료 시 Java 종료·같은 DB 재시작도 통과했습니다. 병행 빌드 중 시작 시간은 51.6초였으며 일반 사용 성능으로 해석하지 않습니다. [측정](native-host-report.json).
- 첫 초안 릴리스 업로드는 체크섬 파일 전송 중 HTTP body 길이 오류로 중단됐습니다. 비공개 초안에서 패키징이 체크섬 생성을 마친 뒤 빠진 자산을 다시 업로드했고, 전체 크기·해시 대조 후 공개했습니다.
- ARM DMG의 설치 복사본·CPU·서명 정적 검사와 ARM 업데이트 압축의 서명·버전·현재 JAR 일치 검사를 통과했습니다. ARM 실기기 실행·Apple 공증·실제 AI 생성은 이번 검사에 포함하지 않습니다.
