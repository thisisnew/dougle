# dougle-bot 자동 검증 시나리오

**최초 설계의211개 시나리오입니다.** 당시 미구현 상태의 계획을 보존한 문서이며 현재 자동 테스트 개수·기능 목록이 아닙니다. 현재 실행 결과는 [검증 기록](implementation-verification.json), 동작은 [실행 계약](../../dougle-bot/SPEC.md)을 확인하세요. 시나리오와 구현 테스트의 전체 대응 검증은 미완료입니다.

공통 fixture·부수효과 판정·중단 주입·배포 기준은 [테스트 계획](TEST_PLAN.md)을 따릅니다. [회사 PC 확인](company-acceptance.md) 20개는 별도입니다.

P0는 승인/유실/혼합/비밀/복구 등 핵심 계약, P1은 그 밖의 지원 기능입니다. 지원 범위의 두 등급 모두 통과해야 내부 시험 배포할 수 있습니다.
