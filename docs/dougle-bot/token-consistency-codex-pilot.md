## 운영 적용을 막는 확인된 결함 (초기 평가 시점)

- 정적 자료가 `확정 뒤`인데 엔진 답변이 `확정 전`이면 현재 Worker가 근거 receipt의 형식만 보고 자동 게시할 수 있습니다. 같은 질문 같은 답을 보장하는 검증 캐시도 Worker에 연결되지 않았습니다. 원본 범위·버전에 연결된 신뢰 가능한 claim 계약과 결정적 렌더링이 필요합니다.
- 초기에는 BigQuery 정상 0건 결과를 모두 `needs_lookup`으로 보냈습니다. 현재 작업 트리에는 질문이 정확한 물리 테이블의 전체 행 존재 여부를 묻고, 같은 테이블의 필터 없는 `COUNT(*)`가 완결된 한 행을 반환할 때에만 0건 자동 안내를 만드는 좁은 경로가 추가됐습니다. 업무 개념과 테이블·필터 매핑이 검증되지 않은 일반 질문은 여전히 보류합니다.
- 실제 봇의 압축 정책, 근거 기록, 세션 복원, 커넥터 조합은 이 합성 평가에서 확인하지 못했습니다. 후보는 검토 모드 opt-in이며 기본값은 기존 정책입니다.

원시 실행 기록은 `.tools/scenario-run-20261107/host/token-bot-*`에 있습니다. 외부 모델 출력은 합성 평가 기록으로만 보관하고 제품 정확도 승인으로 취급하지 않습니다.
