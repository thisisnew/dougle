# 검증 기록 보완과 실행 경합 보호

스킬 **0.8.20 / 봇 0.1.17 배포 준비**입니다. 아직 공개하거나 새 wheel을 만들지 않았습니다. main의 소스 동결 신호 뒤에 새 wheel을 빌드·검증하고, 그다음 기존 wheel을 제거하고 체크섬·배포 사본을 갱신해야 합니다. 이전 릴리스의 검증 기록은 이번 버전의 검증 결과가 아닙니다.

## 오류 해석과 기록만 보완하는 범위

원래 문의 **#33의 출력과 실행 기록이 없으므로 `invalid_verification`의 정확한 원인은 알 수 없습니다.** 형식 진단은 필드·오류 코드로 범위를 좁히는 용도이며, 원래 실패를 재현했거나 답변의 의미가 맞다고 증명하지 않습니다. 원본 도구 결과·답변·민감정보를 진단 로그에 복제하지 않습니다.

같은 문의·작업의 직전 시도에서 답변 본문·출처·상태와 필수 스킬 실행이 통과하고 조사 요구를 확정할 수 있을 때만, 성공한 **비운영 조회 기록**으로 `verification`을 한 번 보완합니다. `question_kind`와 나머지 출력은 바꾸지 않으며 원래 요구와 누적 `required_floor`를 낮추지 않습니다. 원래 receipt와 출처·줄 범위·이미지·보고 문맥으로 전체 검증을 다시 통과해야 저장·게시할 수 있습니다.

운영 현재값(live), 알려진 근거 누락, 불명확한 조사 요구, 다른 문의·작업 또는 세션 복원에는 적용하지 않습니다. 보완 호출의 새 읽기로 원래 누락을 채운 것으로 처리하지 않으며, 필수 스킬 실행은 보완 호출에서도 확인합니다. 표현 보완과 합쳐 기존 한 번의 보완 예산을 사용하고 누적 제한 시간·취소·게시 전 검사를 유지합니다.

## 단일 작업자 유지와 시간의 의미

기본 동시 처리 수는 **1**로 유지합니다. 공유 지식 쓰기의 안전한 조정이 마련되기 전까지 실제 병렬 처리는 보류합니다. 이번 변경은 대기열의 병렬 처리 개선이나 처리량·응답 속도 향상을 제공한다고 주장하지 않습니다.

두 작업자를 두고 엔진 호출만 잠그는 `SerialEngine` 방식은 채택하지 않습니다. 이 방식은 실제 병렬 실행 없이 잠금 대기를 호출 제한 시간에 숨겨, 조회를 시작하기도 전에 시간이 소진될 수 있습니다. 병렬 처리는 공유 메모리 쓰기와 대기열·실행 시간 경계를 함께 해결한 뒤 별도로 검증해야 합니다.

런타임의 소유권·상태 재검사와 처리 중 보호는 취소·종료·전송의 경합을 막기 위해 유지합니다. 이는 병렬 처리 기능의 제공을 뜻하지 않으며, 이미 시작된 원격 전송을 취소하거나 회수할 수 있다는 보장도 아닙니다.

`attempt_tool_timings`는 시도별 관측 시간입니다. `active_ms`는 도구가 하나 이상 진행된 구간, `total_ms`는 겹친 도구 시간을 각각 더한 값이며 둘을 혼동하지 않습니다. `tool_free_ms`는 관측된 도구 활동 밖의 시간으로 순수 모델 추론 시간이 아닙니다. 종료·취소·재시도에서 미완료 도구와 구간을 닫고, 이전 시도의 늦은 결과를 다음 시도의 완료로 세지 않습니다.

## 회귀 검사와 배포 전 확인

합성 검사 대상은 기록만 보완하는 불변 필드·요구 하향 방지·원본 receipt 재검증, live/누락/복원 제외, 단일 작업자 기본값·같은 스레드 배제·취소·종료·전송 경합 보호, 겹친 도구 시간·늦은 결과·누락값입니다. 도구 활동의 중첩 계측은 문의나 모델의 병렬 실행을 뜻하지 않습니다. fake 서비스·임시 DB·가짜 시계 검사는 실제 #33 원인, 회사 서비스 연결이나 모델 답변 품질·속도 개선을 입증하지 않습니다. 이번 준비 단계에서 전체 회귀 통과나 wheel 일치를 주장하지 않습니다.

새 wheel 생성 전에는 `check-skills.mjs`와 `test_package.py`의 새 번들 검사가 통과하지 않는 것이 정상입니다. 검사를 건너뛰도록 변경하거나 이전 wheel의 체크섬을 새 이름으로 바꾸지 않습니다. 소스 동결 후 새 번들·체크섬·사본 일치와 전체 회귀를 확인한 뒤 별도로 공개합니다.

## 전달받은 검증 결과와 남은 확인

아래는 main에서 전달받은 중간 검증 결과이며, 이 문서 편집 중 별도로 재실행한 결과가 아닙니다.

| 구분 | 결과와 한계 |
|---|---|
| 실제 모델 호출 | 합성 검증 기록만 보완하는 격리 평가 **1회**입니다. 도구·스킬·MCP를 비활성화했고 회사 데이터는 사용하지 않았습니다. CLI가 **90초 제한 시간에 종료되어 결과를 받지 못했습니다.** 실제 모델의 기록 보완은 **NOT_VERIFIED**, 비용은 **unknown**입니다. 필수 스킬을 포함한 봇 전체 경로의 검증도 아닙니다. |
| fake 전체 검사 | wheel 검사를 제외하고 **1097개 통과**했습니다. 마지막 소규모 store 정리 **이전** 결과이므로 최종 소스의 통과 수로 사용하지 않습니다. store 정리와 소스 동결 후 main이 최종 수치를 갱신합니다. |
| 격리 합성 회귀 | 변경 전 HEAD의 합성 source-index 사례는 실패했고 수정본은 통과했다는 결과입니다. 해당 합성 회귀의 개선이며, 실제 문의 **#33을 재현하거나 원인을 확정한 결과가 아닙니다.** |

추가 모델 호출이나 회사 서비스 검증을 이 결과에 포함하지 않습니다. 최종 전체 검사와 새 wheel의 소스·체크섬·사본 검증은 main의 소스 동결 후 별도 확인 사항입니다.
