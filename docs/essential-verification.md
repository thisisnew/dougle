# 필수 마무리 검사 — 2026-10-24

추가 기능 개발은 중단합니다. 실제 AI, Claude 간편 연결, ARM 실기기, 설치 앱 업데이트만 마무리합니다. 그 외 개선은 사용자 체험 후 진행합니다.

## 이번에 확인한 것

**0.1.7 후속 검사:** 새 전용 브라우저 로그인으로 만든 인증 → 실제 초안 → 근거 답변 → 중간 SSE(`partialObserved: true`) → 실행 중 취소를 통과했습니다. 사용자 자료가 아닌 가상 자료의 실제 API 검사입니다. 설치형 UI는 별도 검사하며 [최신 결과](release-0.1.7-report.md)를 따릅니다. 아래 표는 0.1.6 당시 기록입니다.

| 검사 | 결과 |
|---|---|
| 동봉 Codex의 기존 로그인 확인 | AUTHENTICATED |
| 실제 Codex로 가상 자료의 지식 초안 생성 | 통과, 별도 DRAFT, 기존 사람 메모 보존 |
| 실제 Codex 근거 기반 답변 | 통과, 인용 포함 |
| SSE 순서 | 근거가 먼저, 완성 답변 이벤트가 나중에 도착 |
| 실행 중 답변 작업 취소 | CANCELLED, 답변 저장 없음. 모델 전송 전에 취소되었을 가능성은 구분 |
| Claude 2.1.31 인증 조회 | UNSUPPORTED, 실제 생성은 실행하지 않음 |
| ARM 실제 실행 | Intel Mac이므로 실행하지 않음 |
| 실제 앱 복사본 업데이트 화면 | 화면 제어 도구의 초기 설정 미완료로 검사 중단 |

**Codex 글자 단위 스트리밍 통과를 의미하지 않습니다.** 기본 설정은 최종 답변 표시이며 이번 검사에서도 중간 출력은 없었습니다. 별도 프로필 스트리밍과 새 브라우저 로그인은 아직 확인하지 않았습니다.

사용자가 이 대화에서 승인한 가상 관측 문장만 외부 AI로 전송했습니다. 사용자 DB·회사 자료·현재 코딩 대화는 전송하지 않았습니다. 인증 파일을 읽거나 복사하지 않았으며 CLI가 기존 인증을 사용했습니다.

## 재현과 증거

실제 호출이므로 계정 사용량이 발생합니다. 명시적 선택 없이는 실행을 거절합니다.

```bash
FORGE_LIVE_CLI=CODEX node scripts/live-ai-smoke.mjs
FORGE_LIVE_CLI=CLAUDE FORGE_LIVE_CLAUDE_COMMAND=/absolute/path/to/claude node scripts/live-ai-smoke.mjs
```

- 기본 검사 대상은 빌드된 Intel 앱의 Java/JAR/Codex입니다. `FORGE_LIVE_RESOURCES`로 다른 설치 복사본의 `Contents/Resources/resources`를 지정할 수 있습니다. 해당 CPU에서만 실행하세요.
- 임시 자료 폴더·세션 토큰을 만들고 인증 보호, 초안, 답변, SSE, 취소를 HTTP로 검사합니다. 종료 후 임시 자료를 정리합니다. GUI 버튼 조작 검사는 아닙니다.
- 검증한 0.1.6 JAR SHA-256: `1348172003e20069168092d784ca789fc14a9e92125508b017309e289eb752c7`.
- Codex 실제 API 검사: 2026-10-24 00:40 KST 시작, PASS. Claude는 호환되지 않는 인증 명령 때문에 생성 전 차단했습니다. 다른 제공자로 자동 재전송하지 않았습니다.
- 별도 `CliCuratorLiveTest`도 동봉 Codex로 **1건 통과·제외 0건**. 생성 구간 7,702ms, 결과 223자. 작은 샘플이며 일반 성능 보장은 아닙니다.
- 새 검사기의 첫 실행은 `FORGE_DATA_DIR` 환경 변수 누락으로 서버 시작에 실패했습니다. 실제 배포 실행기의 환경 계약에 맞춘 뒤 재검사했습니다. 앱 오류가 아닌 검사 도구 오류이며 제품 보안은 변경하지 않았습니다.
- 검사 스크립트 구문과 명시적 선택 누락 시 실행 거절도 확인했습니다. 기존 전체 테스트 600건을 이번에 다시 실행했다고 합산하지 않습니다.

## 남은 조건

### 다음 작업에 필요한 준비

후속 환경 재확인: 현재 호스트는 Intel(`x86_64`)입니다. 사용자 요청 후 Applications 앱을 **0.1.2 → 0.1.7**로 직접 교체했습니다. 화면 제어 도구의 초기 설정 문제는 별도로 남아 있습니다.

- 실제 업데이트 체험: cmux의 Computer Use 초기 설정을 완료한 뒤, 다음 공개 버전으로 실제 메뉴·설치 위치 업데이트를 확인합니다. 0.1.2에는 자동 업데이트가 없어 이번 교체는 검증된 DMG로 진행했습니다. 검사용 버전을 불필요하게 공개하지 않습니다.
- ARM 실기기: 사용 가능한 M 시리즈 Mac이 필요합니다.
- Claude 간편 연결: 배포 주체의 제품 포함 조건 확인과 지원 macOS 결정이 먼저입니다. [조건](claude-readiness.md).

이 준비 없이 완료된 검사를 반복하거나 추가 기능을 늘리지 않습니다. 이번 재확인은 문서만 변경하므로 설치본·피드는 0.1.7을 유지합니다.

### 실제 Applications 설치 — 2026-10-24

- 앱이 실행 중이지 않음을 확인하고 기존 자료 폴더 전체와 이전 앱을 비공개 백업 폴더(`~/Library/Application Support/KnowledgeForgeBackups/날짜-시간`)에 보관했습니다. 백업은 Git에 올리지 않습니다.
- 공개 0.1.7 Intel DMG의 SHA-256과 앱 서명을 확인한 뒤 임시 경로에 복사·검증하고 Applications 앱을 교체했습니다. 원래 자료 폴더는 삭제하거나 교체하지 않았습니다.
- 교체된 앱의 버전·서명을 재검증하고 일반 `open`으로 실행했습니다. 실제 설치 위치의 네이티브 프로세스와 자식 Java, 화면 HTTP 200, 미인증 API 403을 확인했습니다. 앱은 열린 상태로 남겼습니다.
- 사용자 자료 내용·인증 파일을 조회하거나 AI로 전송하지 않았습니다. Gatekeeper·격리 속성·OS 권한을 우회하지 않았습니다. 메뉴 클릭이나 기존 자료 내용의 전수 비교를 검증했다고 보고하지 않습니다.

후속 [공개 앱 교체 검사](published-update-check.md)는 통과했습니다. 실제 0.1.6 설치 복사본에 공개 0.1.7을 적용하고 새 앱을 재실행했습니다. 아래 사용자 설치 위치/메뉴 체험과는 구분합니다.

1. **Claude:** 현재 설치된 2.1.31은 `auth status`를 제공하지 않습니다. 새 호환 도구와 실제 인증이 필요합니다. 앱 포함은 배포 주체의 Commercial Terms 확인 후 진행합니다. [공식 포함·인증 조건](https://code.claude.com/docs/en/legal-and-compliance), [macOS 13 이상 요구사항](https://code.claude.com/docs/en/setup)을 다시 확인했으며 약관에 대신 동의하지 않았습니다.
2. **ARM:** 사용 가능한 M 시리즈 Mac이 필요합니다. 교차 빌드를 실행 검사로 대체하지 않습니다.
3. **업데이트:** `/Applications` 앱은 백업 후 0.1.7로 교체·실행했습니다. 이전 임시 복사본의 자동 업데이트 검사와 실제 설치 위치의 수동 교체를 구별합니다. 다음 공개 버전에서 사용자 메뉴를 통한 업데이트 체험은 아직 남습니다. 화면 제어 초기 설정을 완료해야 합니다.

Codex 전용 인증·중간 SSE·RUNNING 작업 취소는 0.1.7에서 통과했습니다. 취소 검사는 원격 모델 전송 전에 처리됐을 가능성이 있으므로 원격 과금 중단 보장은 아닙니다. 기존 사용자 인증은 복사하지 않았습니다.

## 설치 파일

최초 0.1.6 검사는 도구·문서만 바꿨으므로 당시 설치본을 유지했습니다. 이후 전용 로그인 구현은 앱 변경이므로 **0.1.7 두 CPU 설치본을 다시 빌드·공개**했습니다. [최신 검증·다운로드·피드](release-0.1.7-report.md).
