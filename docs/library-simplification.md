# 자료와 설정 화면 정리

0.1.14는 연결 자료와 업로드 파일을 같은 자료 탐색기에 표시합니다. 연결 자료의 루트 폴더는 중복 표시하지 않으며, 이름을 누르면 내부 파일을 탐색합니다. 아직 동기화하지 않은 자료도 목록에 나타납니다.

- 상단 **전체 동기화**는 연결된 폴더·웹 링크·GitHub를 순서대로 갱신합니다. 업로드 파일은 보관한 복사본이므로 다시 수집하지 않습니다.
- 일부 연결이 실패해도 다음 자료를 처리합니다. 실패 내용은 표시하고, 수집 중에는 중복 실행을 막습니다. 폴더 오류를 파일 수집으로 자동 변경하지 않습니다.
- 경로·반영 버전·최근 동기화 시간은 상세 정보에 접어둡니다. 삭제는 별도 확인이 필요합니다.
- 자동 갱신은 설정에 유지하며 기존 초 단위 범위·동시 수정 검사를 그대로 사용합니다.
- AI 연결은 제공자·모델·연결 버튼 중심입니다. 반복 설명과 확인 전 상태 문구를 없애되 오류, 로그인 동의, 실제 자료 전송 승인은 유지합니다.
- 실행 경로는 기본값 안내와 두 입력란·신뢰 확인·저장으로 줄였습니다. 도구 진단은 접어둡니다.
- 캐릭터는 왼쪽 아래로 옮겼고 질문 기록의 새 질문 버튼은 제거했습니다.

DB/API·자료 저장 위치·인증·일회 전송 승인 계약은 변경하지 않습니다. 연결 확인은 모델의 실제 응답이나 사용 한도 보증이 아닙니다.
