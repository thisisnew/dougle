# 현재 저장소 구성

더글은 호스트 AI에서 실행하는 지식 스킬과 선택형 로컬 Slack 봇으로 구성됩니다. 두 실행 경로가 사용하는 업무 지식은 사용자 홈의 `~/.dougle/`에 저장하며 이 코드 저장소에 포함하지 않습니다.

| 경로 | 용도 |
|---|---|
| `skills/` | 정본 스킬과 참조 규칙 |
| `plugins/dougle/` | Claude·Codex 플러그인 배포 사본 |
| `dougle-bot/` | 선택형 Slack 봇과 테스트 |
| `scripts/` | 스킬·병합·문서·민감정보 검사 |
| `docs/` | 사용법·설계·검증 근거 |

정본 스킬과 배포 사본은 동일하게 유지합니다. 수정 후 검사와 배포 구성은 [개발 안내](skills/development.md), 제품 구성은 [설계 안내](design.md)를 참고하세요.

## 검증 자료와 과거 기록

평가에 사용한 가상 자료와 결과는 검증 근거로 보존합니다. 이전 Slack 카드의 삭제된 동작 차단, 봇 DB 마이그레이션, 금지된 앱 실행 방지 테스트도 현재 호환성과 안전한 실행을 확인하는 자료입니다.

사용하지 않는 제품 코드·빌드·CI·업데이트 피드와 과거 버전별 기록은 [Git 이력](history.md)에서 확인할 수 있습니다. 과거 로컬 생성물은 `.tools/retired-builds-086/`에 분리한 기록이 있습니다. 개발 작업으로 사용자 지식·봇 설정·키체인을 변경하지 않습니다.
