# 현재 저장소 구성

더글은 **AI 스킬 + 선택형 Slack 봇**으로 구성됩니다.

| 경로 | 용도 |
|---|---|
| `skills/` | 정본 스킬과 참조 규칙 |
| `plugins/dougle/` | Claude·Codex 플러그인 배포 사본 |
| `dougle-bot/` | 선택형 Slack 봇과 테스트 |
| `scripts/` | 현재 스킬·병합·문서·민감정보 검사 |
| `docs/` | 현재 사용법·설계·검증 근거 |

사용하지 않는 제품 코드·빌드·CI·업데이트 피드와 중복된 버전별 기록을 현재 트리에서 제거했습니다. 과거 자료는 [Git 이력](history.md)에 남습니다.

실제 평가에 사용한 가상 자료와 결과는 검증 근거로 보존합니다. 이전 Slack 카드의 삭제된 동작을 차단하는 처리, DB 마이그레이션, 금지된 앱 실행을 막는 테스트도 현재 필요한 코드입니다.

로컬의 오래된 생성물은 `.tools/retired-builds-086/`로 분리했습니다. 사용자 지식·봇 설정·키체인은 변경하지 않았습니다.
