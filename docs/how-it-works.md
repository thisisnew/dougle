# 사용법과 작동 원리 — 5분 안내

**0.1.11부터는 [대화 중심 사용법](chat-first.md)을 먼저 보세요.** 자료는 **자료** 탭에 추가하고, 질문은 **대화**, 지난 답변은 왼쪽 **최근 질문**에서 봅니다. 검색 준비는 앱 내부에서 처리하며 지식 문서 편집 메뉴는 없습니다. [현재 검색 원리](internal-search.md). 아래 지식 문서 편집·게시 설명은 기존 데이터/호환 API를 설명하는 이전 흐름이며 현재 화면의 사용 절차가 아닙니다.

**어떤 앱인가요?** 파일·웹·GitHub를 내 컴퓨터에 모으고, 원본 근거로 AI에게 질문하는 개인 지식 서재입니다.
자료 보관·검색에는 AI가 필요 없습니다. AI를 쓸 때만 설치·로그인된 Codex/Claude Code에 승인한 내용을 보냅니다.
처음이라면 [Mac 설치 안내](macos-install.md)부터 읽으세요. [전체 문서 목차](README.md).

Codex는 앱 안의 **AI 연결 → 연결 상태 확인 → 브라우저에서 로그인**으로 준비합니다. 0.1.7부터 이 앱 전용 로그인이 한 번 필요하고, 답변은 생성 중인 글부터 보여 줍니다. 별도 터미널 설정은 없습니다. [로그인 안내](codex-managed-login.md).

## 1. 자료 넣기
1. Workspace를 만듭니다. 프로젝트마다 서랍을 나누는 기능입니다.
2. 파일은 **파일 추가**로 올립니다.
3. 폴더·웹 URL·GitHub는 **자료 연결 → 등록 → 동기화**를 누릅니다. 이후 설정은 **연결한 자료 관리**에 있습니다.
4. 원본은 앱 안에 복사합니다. PC 원래 파일과 원격 저장소를 수정하지 않습니다.

등록한 자료의 이름·분류는 **수정 → 변경 저장**으로 바꿉니다. 원본 파일과 지식 문서는 그대로입니다. [설정 바꾸기](source-metadata.md).

## 2. 검색하기
단어를 입력하고 필요한 도메인을 여러 개 고르세요. 아무것도 고르지 않으면 전체입니다.
원본과 게시된 지식을 함께 검색하며, 미게시 초안은 제외합니다.
검색 결과를 누르면 내용·출처를 확인합니다. **관련 자료**는 같은 선언 심볼·출처로 이어진 자료입니다.
같은 심볼 이름은 함수 호출이나 의미가 같다는 뜻이 아닙니다. [관계 설명](relations.md).

## 3. 지식 문서 만들기
1. 원본 파일을 열고 **이 자료로 지식 문서 만들기 → 근거로 지식 초안 작성**을 누릅니다.
2. 제목·내용·근거 행을 골라 저장합니다. 본문 근거는 `[E1]`처럼 표시합니다.
3. 지식 문서의 **AI로 문서 다듬기**를 펼쳐 전송 미리보기를 확인하고 승인합니다.
4. AI 결과는 별도 초안/제안입니다. 사람이 편집한 문서를 덮어쓰지 않습니다.
5. **검토하고 검색에 포함하기**를 펼쳐 사람이 내용과 출처를 확인한 뒤 게시합니다. 인용 번호 검사가 사실의 자동 증명은 아닙니다.

등록만으로 모든 자료가 자동 백과사전으로 바뀌지는 않습니다.
외부 전송 동의가 필요하므로 현재는 사용자가 근거를 고르고 AI 생성을 승인합니다.

## 4. AI에게 질문하기
**AI에게 질문하기 → 질문 입력 → 참고 자료 찾기 → 이 자료로 답변 준비 → 동의하고 답변 받기** 순서입니다.
검증과 승인 상태 조회는 앱이 처리합니다. 실제 전송은 자료와 전송 내용을 확인하고 동의한 뒤에만 진행합니다. [간단한 화면 안내](simple-workflow.md).
근거가 먼저 나오고, 작업 상태·답변이 SSE로 갱신됩니다. **답변 중단**은 실제 작업 취소입니다.
창 닫기·SSE 연결 해제는 전송 취소와 다릅니다. 다시 연결해도 AI를 새로 호출하지 않습니다.

Claude와 선택적 Codex 스트림의 생성 중 글은 **미검증 임시 출력**입니다.
검사된 최종 답변만 저장합니다. 실패·중단하면 임시 글은 지웁니다.
[채팅](answer-jobs.md) · [Codex 스트림 설정](codex-streaming.md).

이전 답변은 **이전 답변 보기**에서 봅니다. 필요할 때 **대화 정리·이어서 질문하기**를 펼쳐 이전 답변을 직접 선택한 뒤
**문맥 고정 저장 → 새 승인·전송**으로 이어 질문합니다. 자동으로 전체 대화를 보내지 않습니다.
[문맥 선택](context-requests.md).

## 5. 자동 갱신 켜기
**연결한 자료 관리 → 자동 갱신 설정**을 펼친 뒤 **자동 갱신 체크 → 주기 입력 → 갱신 설정 저장**을 누릅니다. 기본 OFF입니다.
앱이 켜진 동안만 작동하고, 실패하면 이전 원본을 유지한 채 더 늦게 재시도합니다.
OFF는 새 수집을 막지만 이미 시작한 수집은 완료할 수 있습니다.
AI 호출·지식 게시를 자동 실행하지 않습니다. [설정](source-polling.md).

GitHub는 같은 commit이면 clone을 생략하고 변경된 blob만 읽습니다.
웹은 서버가 지원하면 304 응답으로 기존 본문을 재사용합니다.
[Git](git-incremental.md) · [URL](url-conditional.md).

## 6. AI 연결하기
상단 **AI 연결 → Codex 선택 → 연결 상태 확인**을 누릅니다. Codex 실행 도구는 0.1.2부터 앱에 들어 있습니다.
로그인이 필요하면 안내에 동의한 뒤 **브라우저에서 로그인**을 누르세요. Claude를 고르려면 현재 별도로 설치된 호환 도구가 필요합니다.
인증 상태를 확인해도 자료를 자동 전송하지 않습니다. 현재 코딩 대화를 앱이 공유하는 것도 아닙니다.
[로그인 안내](provider-connection.md). 기존 실행 경로를 수정해야 하는 경우에만 **고급 설정 → 기존 실행 경로 설정**을 사용합니다.

## 상태와 삭제
- **CURRENT**: 마지막 로컬 수집본과 같음. 원격 최신성·사실 검증 보증은 아닙니다.
- **STALE**: 근거 원본이 바뀜. **MISSING**: 현재 원본을 찾지 못함.
- 원본과 지식은 독립적입니다. 원본 삭제 후에도 지식의 당시 근거 복사본은 남습니다.
- Workspace 삭제는 해당 서랍 전체를 삭제합니다. 중요한 자료는 앱 종료 후 백업하세요.
