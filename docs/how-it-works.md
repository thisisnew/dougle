# Dougle — 5분 사용법

Dougle은 자료를 모으고 AI에게 질문한 뒤 출처를 확인하는 Mac 앱입니다. [설치 안내](macos-install.md) · [문서 목차](README.md).

## 1. Workspace 만들기

사이드바에서 Workspace를 만듭니다. 자료와 질문 기록은 Workspace별로 분리됩니다. 다른 Workspace를 선택하면 해당 자료와 기록으로 전환합니다.

검색 엔진은 설치본에 포함되어 자동으로 준비됩니다. 준비가 끝날 때까지 새 질문 입력은 잠시 비활성화됩니다. 질문 기록은 체크박스로 여러 개를 선택한 뒤 한 번에 삭제할 수 있습니다.

## 2. 자료 추가하기

**자료 → +**에서 파일·폴더·웹 링크·GitHub를 선택합니다. 파일/폴더는 선택 직후, 링크는 주소 입력 후 Enter로 등록하고 자동 동기화합니다. 원본 파일이나 원격 자료를 수정하지 않습니다.

동기화 중에는 실제 파일명·처리 단계와 진행 상태가 표시됩니다. 다른 탭과 Workspace 전환은 완료까지 잠깁니다. 일부 파일이 실패하면 느낌표에 마우스를 올려 원인과 조치 방법을 확인합니다. 다음 동기화에서 완료된 분석을 재사용하며 실패한 파일의 이전 성공 자료는 보존합니다.

큰 파일은 내부 검색 조각으로 나누지만 무제한 처리는 아닙니다. [현재 처리 한도와 복구 방식](ingestion-retrieval-upgrade.md).

## 3. AI와 플러그인 연결하기

상단 **AI 연결**에서 제공자와 모델을 고르고 연결합니다. 로그인이 필요하면 브라우저에서 인증합니다. 연결 확인이나 자료 추가만으로 질문을 AI에 보내지 않습니다. [제공자별 연결 범위](provider-connection.md).

Notion·Jira/Confluence는 **설정 → 플러그인**에서 브라우저 승인을 진행합니다. MySQL은 접속 정보를 입력합니다. 연결한 서비스에서도 Workspace에 등록한 자료만 수집하며 모든 공간을 자동 수집하지 않습니다. [플러그인 사용법·제약](plugins.md).

## 4. 질문하고 출처 확인하기

**대화**에서 질문을 전송합니다. 질문 전송은 관련 자료를 선택한 AI에 보내고 답변을 생성하는 동의입니다. 별도 승인 체크박스는 없습니다. 자료나 AI 연결이 없으면 질문 전송이 비활성화됩니다.

진행 안내 후 답변을 점진적으로 표시하고, 출력이 끝나면 실제로 인용한 출처를 아래에 보여줍니다. AI 답변의 정확성은 원문과 함께 확인하세요.

같은 화면의 후속 질문은 아래에 이어집니다. 이전 대화 전체가 자동으로 AI에 전송되는 것은 아니며 질문별 근거를 찾습니다. 질문창 **+**의 첨부는 해당 질문에만 사용하고 자료 탭에는 등록하지 않습니다. [질문 첨부](question-attachments.md).

## 5. 검색 엔진·자동 갱신

검색 엔진은 설치본에 포함됩니다. 표현이나 언어가 다른 질문도 키워드·의미 검색으로 찾으며 추론은 이 기기에서 처리합니다. **설정 → 검색 엔진**은 준비 상태 확인과 오류 재시도용이며 별도 활성화나 다운로드가 필요하지 않습니다. [내부 검색](internal-search.md).

**설정 → Workspace 관리**에서 자동 갱신 토글과 주기를 설정합니다. 앱이 열려 있을 때 자료를 갱신할 뿐 AI 질문을 자동 실행하지 않습니다.

## 6. 기록·설정·업데이트

- **질문 기록**에서 저장된 질문을 검색·열기·삭제합니다. 사이드바에는 개별 질문을 중복 표시하지 않습니다.
- **설정 → 앱 업데이트**에서 현재 앱 버전과 새 버전을 확인합니다.
- Workspace 삭제는 해당 Workspace의 자료와 기록을 삭제합니다. 중요한 자료는 먼저 백업하세요.
- 앱 교체·복구 시에는 종료 후 백업합니다. [설치·백업·복원](macos-install.md).

예전 지식 문서 편집·게시와 고급 API는 호환을 위해 남아 있지만 현재 기본 화면의 사용 절차가 아닙니다. [아키텍처](architecture.md) · [데이터 모델](modeling.md).
