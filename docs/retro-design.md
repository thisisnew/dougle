# 디자인 — 작은 2D 지식 마을

게임보이 컬러 시대의 RPG와 2D 플랫폼 게임에서 느꼈던 따뜻함을 살립니다. 특정 게임의 캐릭터·로고·지도·이미지는 사용하지 않습니다.

## 바뀐 것

- 첫 화면: 직접 작성한 픽셀풍 SVG 서재·나무·구름 풍경.
- 메뉴: 선택한 칸이 노란색으로 표시되는 게임 메뉴.
- 창과 버튼: 각진 테두리, 단단한 그림자, 누를 때 살짝 들어가는 버튼.
- 색: 크림색 종이, 녹색 잔디, 황금색 강조, 짙은 잉크색.
- 문서 본문: 도트 글꼴을 강요하지 않고 읽기 쉬운 한글/코드 글꼴 유지.

자료 등록·전송 승인·최신성·삭제 기능은 그대로입니다. 장식용 경험치나 가짜 연결 상태를 표시하지 않습니다.
이미지/글꼴을 외부에서 불러오지 않으며, 배경 음악·깜빡임·자동 애니메이션도 없습니다.

## 실제 코드

`frontend/src/PixelLandscape.tsx`가 장식 풍경, `retro.css`가 테마를 담당합니다.
기존 레이아웃 위에 테마를 적용하며 키보드 포커스·좁은 화면·문서 가독성을 유지합니다.
장식 SVG는 스크린리더에서 제외합니다. 버튼의 의미와 실제 동작은 바꾸지 않습니다.

개발 소스에 적용한 디자인입니다. 앞서 검증한 로컬 0.1.2 DMG와 공개 0.1.1에는 아직 포함되지 않았으므로 설치본을 다시 빌드해야 합니다.

## 검증

UI 회귀 테스트 201개 통과, TypeScript/Vite 빌드 성공. 실제 JAR 화면에서 첫 서재·Workspace 생성·자료 탐색기·AI 연결 창을 확인했습니다.
390px 폭도 확인했으며, 검색 입력이 지나치게 좁아지는 문제를 발견해 작은 화면에서는 입력과 버튼을 다음 줄로 나누도록 수정하고 다시 빌드했습니다.
배경 점무늬는 본문과 경쟁하지 않도록 대비를 낮췄습니다. 기능/API/DB 모델은 바꾸지 않았습니다.
