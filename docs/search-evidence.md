# 검색 결과에서 근거 위치 보기

이 문서는 위치 표시 도입 당시 기록입니다. 후속 [게시 지식 통합 검색·v13](published-search.md)도 구현되었습니다.

## 사용법

자료를 검색하면 **검색어 주변 글과 추출 텍스트 줄 번호**가 나옵니다.
예전에는 질문 문장이 그대로 없으면 문서 앞부분을 보여주었습니다.
이제 단어가 떨어져 있거나 한글 조사가 붙어 있어도 Nori 색인 위치를 찾습니다.

1. Workspace에서 검색어를 입력합니다. 도메인은 여러 개 선택할 수 있습니다.
2. `본문 검색어 주변 · 추출 텍스트 94–110행 (일부)`를 확인합니다.
3. 결과를 눌러 파일을 열고 텍스트·코드 분석에서 전체 내용을 확인합니다.

이름·심볼에만 일치하면 **이름·심볼 일치 · 본문 앞부분**이라고 표시합니다.
이때 미리보기 본문을 검색어의 직접 근거로 오해하지 마세요.

## 실제 모델과 코드 대조

`원본 → 저장된 추출 텍스트 → Lucene 본문 단어/위치 → 검색 결과 + 행 범위 → 화면`

- `LuceneSearchIndex.put`: 본문 단어의 문자 위치(term vector offsets)를 함께 색인합니다.
- `LuceneSearchIndex.search`: 검색 단어 중 본문에서 가장 먼저 나오는 위치 주변을 최대 320 UTF-16 코드 단위로 표시합니다. surrogate pair는 자르지 않습니다.
- `SearchIndex.Hit`: `startLine`, `endLine`, `bodyMatch`가 추가되었습니다.
- `SourcePanel`: 본문 일치 여부와 범위를 표시하며 원문 HTML을 실행하지 않습니다.
- SQLite v12 그대로입니다. 시작 시 저장된 추출 결과로 Lucene 색인을 재구성하므로 기존 자료도 적용됩니다.
- 검색 시 수집, Tika/JavaParser 재분석, AI 호출은 하지 않습니다.

줄 번호는 **추출 텍스트 기준, 1부터 시작**합니다. PDF 페이지나 원본 줄 번호가 아닙니다.
빈 본문은 둘 다 0입니다. 마지막 줄바꿈 뒤 빈 줄은 범위에서 제외합니다.
일부 행만 보일 수 있고, 멀리 떨어진 검색어가 모두 표시되지는 않습니다.

## 아직 없는 것

게시 지식 통합 검색은 후속 단위에서 구현했습니다. 영속 청크/스냅샷 바인딩, 관계 검색, 채팅/SSE는 남아 있습니다.
미리보기는 확정 인용문이나 최신성 보증이 아닙니다. 수집 후 색인 반영까지 지연이 있을 수 있습니다.
파일을 열 수 있지만 해당 행 자동 스크롤은 아직 없습니다.
**P4-1 전체 완료가 아니라 원본 검색의 근거 위치 표시만 구현했습니다.**

## 검증

- `SearchSnippetTest`: 떨어진 단어·대소문자, 한글 조사, 메타데이터 구분, 빈 본문, 행 범위, Workspace/다중 도메인 격리, 무결과, 갱신·삭제, 색인 재열기.
- `SourcePanel.test.tsx`: 행 범위·본문 없음 표시, 도메인 선택, 원문 HTML 비실행.
- `scripts/smoke.mjs`: 실제 JAR 검색 응답의 위치와 본문 일치 검사.
- `bash scripts/maven.sh clean verify`: 173개 통과, 실제 CLI opt-in 1개 skip, 실행 JAR 빌드 성공.
- `npm --prefix frontend test -- --maxWorkers=2`: 91개 통과. `npm --prefix frontend run build`: 성공.
- `node scripts/smoke.mjs`: 실제 JAR·재시작 검증 통과. 검색 본문/행 범위/미리보기가 재시작 후 유지됩니다.
- 2026-10-21 macOS Intel/Java 21 측정: 시작 5,386ms, 재시작 5,495ms, 가상 파일 100개 검색 30회 p95 12.45ms. [원시 측정](performance-phase3-foundation.json).
- 단일 프로세스·소규모 순차 요청 결과입니다. 대용량/동시 요청 성능 보장은 아니며 위치 저장으로 늘어나는 색인 용량은 별도 측정이 필요합니다.
- 이번 단위의 실제 브라우저 시각 검증은 수행하지 않았습니다. 실제 외부 AI 요청도 하지 않았습니다.
