## 발견해서 고친 문제

- **저장 실패 후 성공 안내:** 일부 연결에서 식별자의 앞자리0을 잃었습니다. 식별자를 그대로 전달하고 저장 결과를 확인하도록 보완했습니다. 실패3건 재실행 통과.
- **봇과 개인 댓글 규칙 충돌:** 봇에도 서명·승인을 적용하는 지침을 수정했습니다. 필수 스킬 실패 시 봇 답변을 차단하며 일반 ask의 대체 형식과 구분합니다.
- **권한 부족 안내 누락:** fetch 후 원본을 읽지 못하면 필요한 연결·읽기 권한과 다음 행동을 안내합니다.
- **스케줄 상태를 확인 없이 단정:** 중지 기록을 재개 요청으로 해석하지 않고, 실제 타이머 결과가 있어야 완료라고 안내하도록 보완했습니다.
- **대량 파일 검사 병목:** 같은 검사 규칙으로 파일 처리를 묶었습니다. UTF-8 범위를 벗어난 바이트를 구형 시스템 변환기가 허용하는 문제도 보완했습니다.

AI의 문장 판단은 확률적입니다. 재실행 통과를 모든 향후 답변의 보장으로 해석하지 않습니다. 독립 검토의 지적 중 테스트 증거 수집을 제품 행동으로 요구한 경우, 읽기 권한 거절을 코드 확인 성공으로 간주한 경우는 판정 오류로 분리했습니다. 원래 실패 기록은 로컬에 보존했습니다.

표준 시스템 Perl을 쓸 수 있으면 일괄 검사하고, 없으면 기존 셸 방식으로 검사합니다. 새 패키지 설치는 필요 없습니다. 두 경로는 같은 AWK 검사 규칙을 사용하며, 전체 검사·변경 감지·해시 확인을 유지합니다. 의미 검토는 여전히 별도로 필요합니다.
