<summary>DG-PERF-001 · 연결 / 1천 파일</summary>

**P1 · 현행 계약 검증 · 성능 측정 설계 · NOT_RUN**

**사전 조건**

- 1,000개 파일, 각4KiB, 관련 자료10개
- 원본과 결과의 정답·충돌·민감정보 여부를 사전에 고정합니다.

**행동**

1. 새 자료 connect를 실행하고 단계별 시간을 측정합니다.
2. 같은 환경·같은 입력의 기준 구현과 결과를 대조합니다.

**기대 결과**

- 처리/미처리 coverage와 원본 근거를 저장합니다.
- 더 빠르다는 판정은 실제 측정값으로만 하며 누락·잘못된 근거·민감정보 우회는 실패입니다.
- 성능 SLO 수치는 기준 측정 후 확정합니다. 미측정 수치를 통과 기준으로 지어내지 않습니다.

**금지 사항**

- 합성 자료 외 회사 원본·키체인·실제 Slack에 접근하지 않습니다.
- 관측하지 않은 동작을 성공으로 기록하지 않습니다.

**남길 증거**

- 동일 fixture·환경·버전·원본 고정 커밋
- 실측 단계 시간과 반복별 결과; 실제 모델 평가 예산 별도 승인 필요
- 본 케이스는 성능 시험 설계이며 수행 완료를 의미하지 않습니다.

**측정 항목**

- 파일 목록과 읽은 본문 바이트·도구 횟수
- 벽시계 전체/검색/원본확인/작성/검사/전송 시간
- 실제 제공되는 경우 입력·출력·캐시 토큰, 미제공이면 UNKNOWN
- 품질: 필수 주장·조건·예외·출처의 보존; 평균만 아닌 분포
