<summary>DG-SENSITIVE-001 · Slack 봇 토큰 / 본문</summary>

**P0 · 보완 여부를 확인할 수용 기준 · 로컬 합성 자료 · NOT_RUN**

**사전 조건**

- 모든 값은 실사용 자격증명·개인정보가 아닌 합성 fixture입니다.
- 정제 지식 본문에 xoxb 접두사의 합성 토큰를 넣습니다.

**행동**

1. 선택 패키지의 의미 검토와 실제 최종 스캐너를 수행합니다.
2. BLOCK 또는 REVIEW 여부와 업로드 시도 기록을 확인합니다.

**기대 결과**

- 민감정보가 포함되면 전체 publish가 차단되어야 합니다.
- 검사 실패·불완전 상태도 PASS로 바뀌지 않아야 합니다.
- 출력·로그에는 민감 원문을 재출력하지 않습니다.

**금지 사항**

- 실제 비밀값을 fixture로 사용하지 않습니다.
- 자동 삭제/마스킹 후 승인 없이 게시를 계속하지 않습니다.

**남길 증거**

- 의미 검토 결과와 스캐너 판정은 별도로 기록합니다.
- 차단이 필요한 케이스에서 우회되면 기존 기능으로 간주하지 않고 FAIL로 기록합니다.
- 최종 전체 바이트 해시·스크립트 종료코드·원격 쓰기 0회

**관련 기존 검사:** 개별 대응 미완료

- 최초 정상 stage가 검사된 다음 바뀐 파일에 정규식에 잡히지 않는 합성 비공개 계약 조건를 넣습니다.

**행동**

1. 선택 패키지의 의미 검토와 실제 최종 스캐너를 수행합니다.
2. BLOCK 또는 REVIEW 여부와 업로드 시도 기록을 확인합니다.

**기대 결과**

- 민감정보가 포함되면 전체 publish가 차단되어야 합니다.
- 검사 실패·불완전 상태도 PASS로 바뀌지 않아야 합니다.
- 출력·로그에는 민감 원문을 재출력하지 않습니다.

**금지 사항**

- 실제 비밀값을 fixture로 사용하지 않습니다.
- 자동 삭제/마스킹 후 승인 없이 게시를 계속하지 않습니다.

**남길 증거**

- 의미 검토 결과와 스캐너 판정은 별도로 기록합니다.
- 차단이 필요한 케이스에서 우회되면 기존 기능으로 간주하지 않고 FAIL로 기록합니다.
