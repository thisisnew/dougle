# Phase 완료 기준과 현재 상태

**최신 범위: 필수 마무리만 진행합니다.** 아래 확장 기능은 사용자 체험 피드백 전까지 보류합니다. 0.1.7은 전용 브라우저 로그인·실제 초안·근거 답변·중간 SSE·작업 취소 검사를 통과했습니다. 두 CPU 설치 파일 검증·공개는 [진행 기록](release-0.1.7-report.md)을 따릅니다. Claude·ARM 실기기·실제 설치 위치 업데이트 조건은 남습니다. [실제 결과와 필요한 조건](essential-verification.md).

최신 검증: 0.1.7 앱 전용 Codex 로그인·중간 SSE·느린 인증 조회를 연결하고 두 CPU 설치본 검증을 마쳤습니다. [변경과 배포 상태](release-0.1.7-report.md). 위치 변경과 수집 취소는 후속 피드백 범위입니다.

기준: **2026-10-24, 공개 설치본 0.1.7, DB v21**. Intel/Apple Silicon 설치 파일을 제공합니다. Java·Codex·Git이 포함되어 있고 서명된 자동 업데이트를 지원합니다. [설치·피드·검증 기록](release-0.1.7-report.md).

**기본 기능은 설치해서 써볼 수 있는 미리보기 단계입니다. 모든 실제 환경 검증이 끝난 정식 완성판은 아닙니다.** 최신 검사는 Java 378·UI 210·Rust 17건 통과이며 실제 AI 자동 테스트 1건은 제외했습니다. 별도 실제 Codex API, 최종 JAR 통합·강제 종료 복구도 통과했습니다. [결과](release-0.1.7-report.md).

## 필수 마무리 상태

공개 앱 복사본의 **0.1.6 → 0.1.7 서명 업데이트·교체 후 실행**도 통과했습니다. 사용자 설치 위치의 권한 창/메뉴 체험과는 구분합니다. [검사 범위](published-update-check.md). Codex 핵심 검증은 끝났고, 아래 외부 조건 없이 임의로 확장 개발하지 않습니다.

사용자 요청으로 실제 Applications 앱도 백업 후 **0.1.2 → 0.1.7 수동 교체·시작**을 확인했습니다. 앱은 열어 두었으며, 다음 버전의 자동 업데이트 메뉴 체험은 별도입니다. [결과](essential-verification.md).

| 남은 일 | 완료 기준 | 필요한 조건 |
|---|---|---|
| 실제 AI 연결·답변 검증 | Codex 새 전용 인증·실제 답변/초안·근거 우선 중간 SSE·작업 취소·Intel 설치 UI 통과; Claude 남음 | 가상 자료로 실제 검증; Claude 별도 준비 필요 |
| Claude도 별도 설치 없이 사용 | 배포/인증 조건 확인 → 도구 포함 → 두 CPU 설치 검증 | 배포 주체의 약관·사용 방식 확인, macOS 지원 정책 결정 |
| Apple Silicon 실기기 검증 | ARM Mac에서 설치·실행·수집·검색·AI 연결·종료 확인 | 실제 ARM Mac; 교차 빌드·정적 검사만으로 대체 불가 |
| 실제 설치 위치 자동 업데이트 | 공개 앱 복사본 교체·같은 가상 DB의 자료/사람 수정/게시본/출처 보존·재실행 통과; 실제 사용자 메뉴 체험 남음 | 실제 설치 앱은 0.1.7 실행 확인; 메뉴 검사는 화면 제어 초기 설정과 차기 공개 버전 필요 |

## 그다음 개선할 기능

- 수집 중 진행 상태 표시·취소, 등록한 Source의 위치 변경. 이름·도메인 수정은 0.1.6에 구현했습니다.

- 비공개 GitHub 인증, Git 캐시·브랜치 선택, 대용량 자료 처리.

이들은 기본 체험 이후의 확장입니다. 특히 비공개 회사 저장소 사용에는 별도 인증 구현이 필요합니다. 전체 설계·인수 조건은 [백로그](backlog.md)를 따릅니다.

## 모든 단계의 완료 조건

1. 실제 코드와 사용자 진입 경로가 있어야 합니다. 빈 모듈·가짜 성공 화면은 완료가 아닙니다.
2. 정상·오류·격리·재시작을 해당 기능 테스트로 확인합니다. 실패는 원인과 해결 여부를 기록합니다.
3. 원본과 지식은 독립 보관합니다. 기존 지식·사람 편집을 자동으로 덮어쓰지 않습니다.
4. 검색과 AI를 분리합니다. 질문 때 전체 재분석하지 않으며 외부 전송은 건별 승인합니다.
5. 실제 코드·모델링·사용법을 대조하고 GitHub에 함께 갱신합니다.
6. 매 작업 종료 시 HANDOFF·현황·관련 설명·실제 테스트 결과를 갱신하고 푸시합니다. 앱 변경은 설치 파일·업데이트 배포까지 완료하고, 문서/테스트만 변경했다면 기존 설치본을 유지한 이유를 기록합니다.

## 현재 안전 제한

- 파일당 10 MiB, Source당 500개/50 MiB, 경로 깊이 16단계, 추출 텍스트 500,000자.
- SQLite BLOB 저장·단일 로컬 사용자용이며 데이터 암호화는 없습니다.
- 공개 HTTPS(443)·공개 GitHub 기본 브랜치만 지원합니다. SSH·서브모듈·심볼릭 링크는 제외합니다.
- Source 전체 과거 이력은 보관하지 않습니다. 지식에서 인용한 당시 원본은 별도로 보존합니다.
- CURRENT는 마지막 로컬 수집본과 일치한다는 뜻이지 원격 최신성·사실 검증이 아닙니다.
- 앱 종료/잠자기 중 폴링하지 않습니다. 회사 GitHub Actions를 수정하지 않습니다.
- Intel 실행 검증과 ARM 교차 빌드·정적 검사를 구분합니다. 공증은 없으며 Windows 패키지는 제공하지 않습니다.
