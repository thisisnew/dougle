# Dougle 0.1.31 — 간결한 대화 화면

- 대화의 `자료 더 찾아보기`, `브라우저 화면 조사` 수동 진입 버튼을 제거했습니다.
- 기존 자동 검색·답변 흐름과 필요한 승인 절차는 유지합니다.
- 0.1.30의 검색·후속 질문 문맥·대용량 추출 수정도 포함합니다.

Intel 및 Apple Silicon용 DMG, 서명된 업데이트 파일과 체크섬을 제공합니다. 사용자 요청으로 **공개 Preview 릴리스**로 전환했습니다. 자동 업데이트 피드는 변경하지 않습니다. Intel 로컬 설치 확인과 ARM 정적 검증을 구별하며 ARM 실기기·새 Mac 인수·Apple 공증은 완료되지 않았습니다.

이전 버전에서 본문이 잘린 자료는 다시 동기화하거나 재분석/재업로드해야 합니다. 전체1,000개 인수 완료나 검색 속도 개선을 의미하지 않습니다.
