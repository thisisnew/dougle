# 제한형 팀 설정 화면 제거

최종 반영: Intel0.1.26 설치·실행과 서명/버전/JAR·DB v28·비인증403 확인을 마쳤다. [설치 기록](local-install-0.1.26-20261027.json). 아래0.1.25 설치 전 표현은 화면 검증 당시의 기록이다.

사용자는 자료 전체 내보내기를 원하며 기존 구성 JSON·제한형 ZIP 이전은 원하지 않는다. 전체 자료를 내보내지 못하는 현재 기능 대신 최신 소스에서 팀 설정 메뉴, 화면 경로, 세 화면 컴포넌트를 삭제했다. 원본 개별 다운로드와 기존 자료·DB·내부 호환 API는 보존한다. 새 전체 내보내기를 구현했다고 주장하지 않는다.

- `App.test.tsx`: 29건 통과. Workspace 유무에 따른 메뉴/화면 비노출, 이전 API와 다운로드를 호출하지 않는 회귀 포함. 삭제된 화면에만 해당하는 테스트는 함께 제거했다.
- 실제 React 개발 화면을 Ego 브라우저 TaskSpace16에서 열고 설정 버튼을 클릭해 Workspace 관리·플러그인만 표시되는 것을 확인했다. [검토한 화면](../screenshots/settings-without-transfer-20261027.png).
- 브라우저 검사는 합성 Workspace 응답만 주입한 프런트엔드 검사다. 사용자 자료·인증·업무 서버 및 실제 AI에 접근하지 않았으며 설치 앱/네이티브 업데이트 화면 검사로 확대 해석하지 않는다. 검색 엔진 mock은 실제 준비 상태 검증이 아니므로 대화 기능을 테스트하지 않았다.
- TaskSpace16은 종료했고 전용 Vite4178 프로세스를 종료했다. 설치된0.1.25는 별도 새 패키지 설치 전까지 기존 화면이다.

로그: `/tmp/dougle-team-settings-removal.log`. 화면 제거를 전체 자료 내보내기 지원이나 기존 내부 이전 API 삭제로 설명하지 않는다.
