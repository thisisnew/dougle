# 9. 회귀 검사·배포·회사 수용 시험

## 목적과 변경
기존 답변·동시 처리·취소·근거 검증·지식 저장·설치 경로를 전체 검사하고, 테스트한 소스와 실제 배포 wheel/ZIP이 같은지 확인합니다. 스킬 0.8.29 / 봇 0.1.26입니다. 실제 회사 봇·Slack·지식은 이 개발 Mac에서 변경하지 않았습니다.

## 현재 확인 결과
- 전체 봇 pytest 1,709개 통과, 기존 기대 실패 2개. 이후 평가기 보완 4개와 비용 진단 9개 검사도 통과했습니다. 최종 CI 결과는 아래 배포 상태에 기록합니다.
- 기대 실패는 업무 개념과 실제 테이블/필터 매핑이 없는 일반 BigQuery 자동 답변 계약입니다. 실제 테이블 전체 COUNT(*) 0건의 한정 자동 안내는 별도 정상 검사로 유지합니다. 403/404를 0건으로 바꾸지 않습니다.
- Ruff, 스킬 구조 291개, 병합 결정 64개·Git 전송 6개, 게시 구조 15개와 민감정보 검사 연결, 민감정보 기본/legacy 각각 84개, 대규모 패키지 20개, 플러그인 두 경로 검증 통과.
- 실제 Codex 합성 모델 호출 12회: 2질문 × 기준/후보 × 3회. 기존 1,637,504 → 후보 574,675토큰, 64.91% 감소. 실패 0회. 후보의 확인된 사실 오류·필수 사실 누락 0건, 반복 핵심 사실 일치. 기존 답변 1회는 식품 접수 화면 예외를 생략했고 결과에 보존했습니다.
- 실제 모델 출력·사용량·정답 사실·원문은 같은 폴더 evaluation-trials.json/evaluation-plan.json/model-originals.json/model-evaluation.json에 있습니다. 모든 모델 실행은 합성 fixture입니다. 새 Claude 봇/회사 커넥터 성능을 직접 측정한 수치가 아닙니다. 캐시 비용·구독 소모량도 별도입니다.

## 회사에서 확인할 순서
1. 설치본·설정·지식·봇 DB를 백업하고 기존 봇을 정상 중지합니다. 실행 중인 SQLite DB를 단순 복사하지 말고 중지 후 복사 또는 SQLite backup을 사용합니다.
2. 0.8.29 플러그인을 업데이트/리로드하고 새 대화에서 사용합니다. 설치된 dougle-bot/scripts/bot.sh prepare로 0.1.26 런타임을 준비합니다. 기존 프로세스가 완전히 중지됐는지 확인합니다.
3. 사용자의 한도 제거 요청에 따라 기존 config.toml의 [engine]에서 timeout_seconds/max_turns/max_budget_usd_per_call/daily_budget_usd 네 설정을 제거합니다. 새 버전에서 생략은 상한 없음입니다. 기존 숫자는 업데이트만으로 자동 삭제되지 않습니다. 다른 설정·소스 등록·인증정보는 유지합니다.
4. 새 런타임으로 시작하고 status에서 running_version=0.1.26, update_required=false, 정상 시작을 확인합니다. 오류가 나면 start를 반복하기 전에 실패 단계와 usage --attempts를 보관합니다.
5. 압축 시험은 명시적으로 compact_policy=true를 유지합니다. prompt_cache_ttl/effort는 05 문서 조건으로 비교하고 여러 요인을 동시에 바꾸지 않습니다. 새 index-build를 한 번 실행해 위치 색인을 만듭니다. 원문 변경 후에는 다시 만들며 없어도 기본 탐색은 동작합니다.
6. “회송폐기때 이메일은 언제보내?”를 같은 조건에서 3회, 실제 원문 변경 후 1회 시험합니다. 시점·조건·예외·불확실성이 같은지 비교합니다. 문구가 완전히 같은지를 핵심 사실 일관성과 구분합니다.
7. 원래 여섯 질문과 후속 질문을 07 문서 조건으로 비교합니다. 실패한 질문도 버리지 않습니다. 실제 실패 문의와 재시도 사유를 status와 usage --attempts로 함께 내보냅니다.
8. 게시 검증은 사용자가 지정한 지식 저장소와 범위에서 06 문서대로 실행합니다. Markdown 구조 기록을 포함한 최종 stage 전체를 민감정보 검사합니다. 기존 자료를 빈 원격으로 간주하거나 기존 ID를 재발급하지 않습니다. 설치만으로 전체 마이그레이션·자동 publish를 실행하지 않습니다.
