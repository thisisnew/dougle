# Dougle 0.1.37 — 코드 파일 판독과 검색 제외 분리

2026-10-29 20:42 KST [공개 Preview](https://github.com/thisisnew/dougle/releases/tag/v0.1.37-preview.1). 소스 커밋 `57832d3`, 공개 자산 3개의 SHA-256과 크기를 로컬 파일과 대조했다. 자동 업데이트 피드는 변경하지 않았으므로 설치 파일을 직접 내려받는다.

회사 Mac의 스크린샷에 나온 Gradle 판독 실패와 텍스트 없는 이미지의 실패 집계를 대상으로 수정했다. 실제 회사 파일·오류 로그는 제공받지 않았으므로 해당 PC의 모든 오류 원인을 확정하지 않는다.

## 변경

- Gradle/Groovy/Kotlin/JavaScript/TypeScript/SQL/YAML/설정 파일 등을 Tika 자동 판별 대신 스트리밍 텍스트로 읽는다. 원본이나 빌드 스크립트를 실행·수정하지 않는다.
- UTF-8·UTF-8 BOM·UTF-16 LE/BE BOM, 대소문자 확장자·하위 경로를 지원한다. 잘못된 인코딩과 바이너리 내용은 검색에 넣지 않고 구체적으로 안내한다.
- 텍스트 없는 이미지는 분석 실패 건수와 폴더 경고에서 제외한다. 원본은 보존하고 Source 상세 정보에 검색 제외 건수를 표시한다. 검색 가능한 파일이 없는 폴더는 READY로 표시하지 않는다.
- 실패/미지원 분석 체크포인트를 그대로 재사용하지 않는다. 동일 파일도 재동기화하면 재분석하며 정상 파일과 완료 체크포인트는 재사용한다.
- 원본 수집 제한·검색 색인 방식·읽기 전용 정책은 유지한다. OCR 추가, 암호화 파일 해독, 모든 인코딩 지원을 의미하지 않는다.

## 검증 항목

- Gradle 및 코드/설정 11종의 본문 판독, BOM 3종, 바이너리 위장 파일 거부.
- 코드+텍스트 없는 PNG → 검색 가능; 재동기화 후 동일 상태와 검색 유지.
- 실제 실패 1개+텍스트 없음 1개 → 실패 1개만 집계, 제외 수는 별도 표시.
- 실패 체크포인트 및 이전 UNSUPPORTED → 원본 변경 없이 재동기화 복구.
- 텍스트 없는 파일만 있는 폴더 → 검색 가능으로 오인 표시하지 않음.
- 정상 분석 체크포인트 재사용·정상 파일 재분석 방지·부분 실패 원본 보존 회귀 검사.
- UI 상세 정보의 제외 수 표시와 정상 폴더 실패 경고 없음.

## 테스트 결과

- 변경 영역 최종 재검증: AnalyzerTest 20개, SourceIntegrationTest 45개 통과.
- UI 656개 및 opt-in 50개 통과. Node 177개 직렬 실행 통과, Rust 24개 통과.
- 전체 Java 최종 실행: 1,251개 중 1,223통과·25생략·3실패. 실패는 기존 CodexAppServerTest·ProviderConnectionAdapterTest·ProviderLoginAdapterTest의 시간 제한/인증 상태 검사다. 이번 판독·집계 변경과 별개의 테스트이며 수정하지 않았다. 관련 클래스와 변경 영역을 묶은 재실행에서도 CLI 타이밍 2개가 실패했다. 전체 테스트 통과로 보고하지 않는다.
- 최초 전체 Java는 1,249개 중 기존 Codex 시간 제한 검사 1개 실패; 이후 신규 회귀 2개를 추가했다. Node 최초 병렬 실행은 프로세스 시작 타이밍 2개 실패 후 동일 코드 직렬 실행에서 통과했다.
- 동봉 런타임의 새 HOME 설치·별칭 프로필/자동 탐색 검사는 통과했다. 가상 CLI를 사용하며 실제 회사 계정 인증 성공을 의미하지 않는다.

동봉 Java/JAR의 별도 HOME에서 AI 없이 코드 수집 → Gradle 검색 → 부분 실패 항목 제거 → READY 복구 → 텍스트 없는 파일 제외 수 유지 → 분석 실패 목록 비어 있음 → 원본 불변을 확인했다. GitHub 차단과 Confluence 인증 안내도 유지된다.
