# Dougle · 더글

물어보면 함께 풀어주는 똑똑한 동료입니다. 사용자 이름 Douglas에서 가져왔습니다.

- 표기는 **Dougle**, 읽기는 **더글**입니다.
- 로고는 둥근 기하학적 느낌의 Mac 내장 **Avenir Next**, 중간 굵기입니다. Google 전용 서체나 로고 파일은 복제·동봉하지 않습니다.
- 파랑·코랄·골드·초록을 글자에만 사용합니다. 화면은 흰색, 선택 상태는 연한 블루입니다.
- 대화 시작 화면에는 큰 로고와 질문창을 둡니다. 로고의 `o`를 투명 캐릭터의 얼굴로 대체하며 코랄 원형 테두리 안에 배치합니다. 오른쪽에는 캐릭터를 중복 표시하지 않습니다. 접근성 이름은 Dougle을 유지합니다. 입력 안내는 **더글한테 물어보기**입니다.
- 질문창의 ‘내 자료 기반 · 새 질문’ 설명은 제거하고 첨부·전송 버튼만 남깁니다. 대화 메뉴를 누르면 새 질문을 시작합니다.
- 질문 전송이 관련 자료의 선택 AI 전송/실행 동의입니다. 별도 답변 준비·동의 체크박스는 표시하지 않으며 업로드만으로 AI를 호출하지 않습니다.
- 사이드바에는 개별 질문과 캐릭터를 표시하지 않습니다. 저장 이력은 질문 기록 탭의 세로 리스트에서 확인·삭제합니다.
- 대화는 말풍선, 질문 기록 메뉴와 기록 행은 시계·되돌아보기 아이콘으로 구분합니다.
- 새 투명 캐릭터는 `frontend/src/assets/dougle-mascot-transparent.png`이며 기존 캐릭터 자산은 보존합니다. 공통 Wordmark·Dock 아이콘·시작/오류 안내창 모두 `o`에 같은 얼굴을 배치합니다. 안내창 CSP는 자체 이미지에만 접근을 허용합니다. 집 그림과 입체 워드마크는 제거했습니다.

## 기존 자료는 그대로

0.1.32 작업본부터 앱은 `Dougle.app`, 배포 파일 접두사는 `Dougle`, 앱 ID는 `dev.dougle.desktop`, 내부 JAR는 `dougle.jar`, DB는 `dougle.sqlite`다. Java 패키지는 `dev.dougle`로 통일한다. DB 스키마는 v30을 유지한다. 기존 앱을 종료한 뒤 이전 데이터 폴더 전체를 원자적으로 이동하고 WAL checkpoint 후 DB 이름을 바꾼다. 새·구 폴더가 모두 있으면 자동 병합하거나 덮어쓰지 않는다. 자료·인증 파일과 업데이트 서명 키 자체는 보존한다. 구버전 서명 자산·다운로드 주소는 불변 이력으로 유지하며 이름 변경 이전 버전의 자동 업데이트는 검증 전까지 제공하지 않는다.

`Wordmark.tsx`의 기본 브랜드는 얼굴을 포함합니다. 스크린 리더에는 글자를 여섯 번 읽지 않고 Dougle 한 단어로 전달하며, 고대비 모드에서는 시스템 글자색을 사용합니다. 사이드바와 메인 상단에는 중복 로고/Workspace 이름을 표시하지 않습니다. AI 연결 전 질문 전송 잠금·자료 첨부·내부 승인 검증은 바뀌지 않습니다.

상표 등록이나 동명 서비스 조사 완료를 의미하지 않습니다. [검증·배포 기록](release-0.1.13-report.md).

## 아이콘 재현

Mac에서 `swift scripts/render-dougle-icon.swift /tmp/dougle-icon.png`로 1024px RGBA 원본을 만들고 Tauri icon 도구로 ICNS와 크기별 PNG를 생성합니다. AppKit의 내장 Avenir Next로 렌더링하며 외부 폰트나 Google 로고 파일은 포함하지 않습니다.
