# Dougle · 더글

물어보면 함께 풀어주는 똑똑한 동료입니다. 사용자 이름 Douglas에서 가져왔습니다.

- 표기는 **Dougle**, 읽기는 **더글**입니다.
- 로고는 둥근 기하학적 느낌의 Mac 내장 **Avenir Next**, 중간 굵기입니다. Google 전용 서체나 로고 파일은 복제·동봉하지 않습니다.
- 파랑·코랄·골드·초록을 글자에만 사용합니다. 화면은 흰색, 선택 상태는 연한 블루입니다.
- 대화 시작 화면에는 큰 로고와 질문창을 둡니다. 입력 안내는 **더글한테 물어보기**입니다.
- 질문창의 ‘내 자료 기반 · 새 질문’ 설명은 제거하고 첨부·전송 버튼만 남깁니다. 사이드바의 새 질문 동작은 유지합니다.
- 질문창 하단의 전송 동의 안내 문구는 표시하지 않습니다. 실제 답변 준비·건별 전송 동의는 그대로 유지합니다.
- 사이드바의 ‘최근 질문’ 제목과 빈 목록 안내도 제거합니다. 저장된 질문이 있을 때만 목록과 새 질문 버튼을 표시합니다.
- 대화는 말풍선, 질문 기록 메뉴와 기록 카드는 시계·되돌아보기 아이콘으로 구분합니다.
- 기존 수트 캐릭터는 사이드바에 유지합니다. Dock 아이콘은 흰색 둥근 타일 위 다색 Dougle 로고로 바꿉니다. 집 그림과 입체 워드마크는 제거했습니다.

## 기존 자료는 그대로

이름과 화면만 바꿉니다. 앱 ID·DB v22·인증·업데이트 주소·서명 키는 유지합니다. 호환성을 위해 설치 파일명 `Knowledge Forge.app`과 배포 파일 접두사 `Knowledge.Forge`도 유지합니다.

`Wordmark.tsx`를 사이드바/대화에 공통 사용합니다. 스크린 리더에는 글자를 여섯 번 읽지 않고 Dougle 한 단어로 전달하며, 고대비 모드에서는 시스템 글자색을 사용합니다. AI 연결 전 질문 전송 잠금·자료 첨부·건별 승인은 바뀌지 않습니다.

상표 등록이나 동명 서비스 조사 완료를 의미하지 않습니다. [검증·배포 기록](release-0.1.13-report.md).

## 아이콘 재현

Mac에서 `swift scripts/render-dougle-icon.swift /tmp/dougle-icon.png`로 1024px RGBA 원본을 만들고 Tauri icon 도구로 ICNS와 크기별 PNG를 생성합니다. AppKit의 내장 Avenir Next로 렌더링하며 외부 폰트나 Google 로고 파일은 포함하지 않습니다.
