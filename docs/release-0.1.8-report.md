# 0.1.8 — AI 연결 상태와 꼬마 탐정 아이콘

현재 빌드·검증 중이며 공개 설치본과 업데이트 피드는 아직 0.1.7입니다.

- AI 연결을 열면 인증 상태를 자동 확인합니다.
- 초록색 로그인 확인, 로그인 필요, 확인 중, 실패를 구별합니다.
- 창을 닫아도 상단에 마지막 결과를 표시합니다. 원격 연결 성공으로 단정하지 않습니다.
- DB v21, API와 전송 승인 경계, 업데이트 서명 키는 그대로입니다.
- Dock/Finder 아이콘을 녹색 안경·크림색 배경의 독자적인 꼬마 탐정으로 교체합니다. 생성 원본에서 Tauri 아이콘 도구로 PNG/ICNS를 만들며 두 CPU 앱에 같은 아이콘을 포함합니다.
- [사용법·구현 대조](ai-connection-indicator.md).

## 검증

- 변경부 UI 17건, 최종 전체 UI 214건, Java 378건(실제 AI 자동 검사 1건 제외), Rust 17건 통과. 설치 패키지 검증은 진행 중입니다.
- 실제 브라우저에서 가상 도구의 로그인 필요 → 동의 → 로그인 확인 → 창 닫은 뒤 상단 결과 보존을 확인했습니다. 화면은 사용법 문서에 첨부하며 실제 AI 호출은 없습니다.
- Intel 설치 UI 검사의 기존 수동 확인 대기가 새 자동 확인 결과를 재사용해 두 번 실패했습니다. 자동 확인 완료 뒤 재확인 시작(`CHECKING`)·새 결과를 순서대로 기다리도록 검사기를 수정했습니다. 제품 코드나 인증 보호는 변경하지 않았습니다.
- 통합 JAR 검사 통과. 가상 파일 100개 검색 30회 p50 10.70ms, p95 18.73ms이며 작은 개발 환경 자료의 측정값입니다.
- 사용자가 제공한 화면에서 0.1.7의 실제 렌더링은 정상이었습니다. 이전 흰 화면은 도구 캡처와 실제 화면의 차이로 분류하며 앱 렌더링 오류로 처리하지 않습니다.
