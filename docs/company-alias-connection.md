# 회사용 별칭 연결 — 0.1.34

0.1.35에서는 기본 도구 선택 시 인증 확인과 현재 실행 환경 적용을 함께 수행한다. 아래 별칭 해석 범위는 유지하며, 새 연결·실패 보존·재시작 후 답변 시나리오는 [0.1.35 검증 기록](release-0.1.35-report.md)을 따른다.

## 문제와 수정 범위

사용자 회사 Mac에서 `claude-work`가 alias이고 터미널에서는 실행되지만 Dougle의 인증 확인이 실패했다. 별칭 본문이나 인증정보는 전달받지 않았다. 따라서 실제 회사의 실패 원인 전체가 확정된 것은 아니다.

기존 구현은 환경변수가 포함된 별칭을 거부했고, 네이티브 호스트가 기본 `claude`의 절대 경로를 먼저 지정하여 Java 자동 탐색도 건너뛸 수 있었다. 호스트의 중복 Claude 탐색을 제거했다. 기본 명령 탐색 시 지원하는 환경 별칭이 하나이면 이를 사용한다. 저장한 사용자 선택과 명시적 실행 명령은 덮어쓰지 않으며, 여러 계정 별칭은 임의로 고르지 않는다.

지원 예시:

```sh
alias office='CLAUDE_CONFIG_DIR="$HOME/Company Profile" claude'
alias work-ai='env ANTHROPIC_BASE_URL=https://example.invalid ANTHROPIC_AUTH_TOKEN=synthetic claude'
```

이름을 `claude-work`로 하드코딩하지 않는다. 설치된 기본 `claude`만 있는 환경도 그대로 지원한다. Claude 설정 폴더 분리는 [공식 인증 문서](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)의 방식이다.

## 안전한 실행

- 셸 rc 파일을 source하거나 로그인 셸을 실행하지 않는다. 알려진 사용자 프로필의 제한된 크기 내에서 단일 행 별칭만 읽는다.
- 리터럴 환경 대입 + 실행파일 한 개만 해석한다. `env` 접두어, 따옴표로 묶인 공백 경로, 계정 폴더의 `~`, `$HOME`, `${HOME}`를 지원한다.
- 제공자별 환경변수 allowlist만 전달한다. 임의 PATH/HOME/NODE_OPTIONS, 명령 치환, 파이프, 리디렉션, 셸 연산자, 추가 CLI 옵션은 거부한다. 참조 변수·외부에서 source한 파일·복잡한 함수는 지원하지 않는다.
- 환경값은 프로세스 메모리에만 보관하며 API·DB에는 불투명 식별자만 전달한다. 인증정보를 포함한 실행 스크립트를 디스크에 만들지 않는다.
- 별칭의 실행파일/환경이 바뀌면 식별자가 달라진다. 진행 중 요청의 실행 설정은 바꾸지 않으며 저장한 선택은 재시작 후 적용한다. 사라지거나 변경된 별칭은 정상 인증으로 표시하지 않는다.
- 인증 확인·로그인·답변 생성·Codex app-server 모두 같은 실행 계획을 적용한다. Codex 전용 HOME 격리 및 답변의 읽기 전용/도구 차단 옵션은 유지한다.

## 연결 UX와 브라우저 대안

별도의 `다른 AI 도구 찾기` 버튼을 제거했다. 연결 실패 시 자동 탐색 결과를 같은 흐름에서 표시한다. 실패 이유는 시간 초과/인증 명령 거부/해석 불가 응답/설정 변경으로 구분하며 원문 stdout/stderr는 노출하지 않는다. 인증 성공은 원격 모델 호출 성공을 의미하지 않는다.

로그인이 필요한 경우 기존 공식 Claude Code 브라우저 로그인 흐름을 동일 계정 환경으로 실행한다. Claude Desktop을 열었다는 이유로 인증 완료 처리하거나 Desktop 쿠키/토큰을 추출하지 않는다. 회사 계정 실패를 개인 계정·별도 과금으로 자동 대체하지 않는다. Claude 런타임 신규 동봉/자동 설치는 이번 변경에 포함되지 않는다.

## 검증

`ShellAliasLaunchTest`는 가상 HOME에서 회사 프로필이 없으면 실패하는 실행파일을 사용하여 발견→인증→답변 실행기의 동일 환경 전달을 검증한다. 실제 AI를 호출하지 않는다. 정상 기본 명령, NVM, 공백 경로, 별칭 이름 차이, 비밀값 비노출, 위험 셸 구문 거부, Codex 격리 환경도 검사한다.

`node scripts/fresh-install-smoke.mjs <resources> --profile-alias`는 실제 동봉 Java/JAR로 빈 HOME·최소 PATH·별칭 자동 선택·설정 저장·프로세스 재시작·가상 인증·파일 업로드·한국어 검색을 검사한다. 회사 SSO나 ARM 실기기 인증 통과로 집계하지 않는다.

최종 실행/패키지/공개 결과는 `release-0.1.34-report.md`를 따른다. 회사 Mac 재확인 전에는 모든 별칭 연결이 해결됐다고 주장하지 않는다.
