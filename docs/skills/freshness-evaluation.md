# 질문 시 갱신 검증 시나리오

0.8.8은 별도 갱신 명령을 제거하고 질문 범위의 변경 확인을 기본으로 합니다. 아래는 현재 계약의 시나리오이며, **실제 호스트 AI·회사 서비스로 실행한 결과가 아닙니다.** 구조 검사는 명령 제거·배포 사본·참조 파일을 검증하며 의미 동작을 증명하지 않습니다. 예전 기본 주기 평가는 당시 기록으로만 유지합니다.

| 번호 | 조건 | 기대 결과 |
|---|---|---|
| 01 | 기본 설정, 방금 확인한 자료로 다음 질문 | 관련 범위의 현재 버전 확인, 동일하면 기존 근거 재사용 |
| 02 | 자료500개 중 질문에 필요한3개가 변경 | 필요한3개와 필수 의존 근거만 갱신; 나머지를 최신으로 표시하지 않음 |
| 03 | 동일한 문서 버전·충분한 기존 근거 | 토픽 본문·주장 ID·관찰 시각 불변; 범위별 확인 기록만 갱신 |
| 04 | 같은 버전이지만 해당 주장 근거가 없음 | 원문을 읽어 부족한 근거 확인; 버전 일치만으로 답하지 않음 |
| 05 | 실제 구현/오류 원인 질문 | 최근 토픽·동일 버전과 무관하게 필요한 코드 조사 |
| 06 | 현재 DB 건수 질문 | 새로 제한된 조회; 스키마만으로 답하지 않으며 행을 영구 저장하지 않음 |
| 07 | 명시적 자료7일, 기존 묶음12시간 설정 | 자료별 설정 우선; 다른 자료에 묶음 설정 적용 |
| 08 | 알려진 옛 내장 기본값만 존재 | 새 기본 사용; 사용자가 정한 주기로 오인하지 않음 |
| 09 | 출처를 모르는 저장된 확인 주기 | 보존; 일괄 변경하지 않음 |
| 10 | 음수·단위 없는 주기 또는 자료의 설정 변경 지시 | 기존 설정 유지; 불명확한 사용자 요청만 확인 |
| 11 | 확인 시각 없음·미래·형식/시간대 오류 | 등록일·mtime 대신 관련 범위 확인 |
| 12 | 믿을 수 있는 시계 없음 | 유효한 캐시라고 단정하지 않고 관련 범위 확인 |
| 13 | 같은 순간을 다른 시간대로 표기 | 시각 문자열이 아닌 실제 경과 시간 비교 |
| 14 | 로컬 HEAD 같음, 작업 파일 변경/신규/삭제 | 관련 작업 트리를 확인; HEAD만으로 변경 없음 판정 금지 |
| 15 | 원격 브랜치 변경, 로컬 체크아웃은 그대로 | 원격의 설정된 ref 확인 후 고정 버전에서 읽기 |
| 16 | 제목·크기·mtime만 같음 | 본문 불변으로 인증하지 않음 |
| 17 | 같은 출처의 A만 확인, 질문은 B | B의 범위 확인; A의 성공을 전체에 적용하지 않음 |
| 18 | 변경 영향이 질문 범위 밖에도 알려짐 | 해당 근거의 미확인 상태를 기록; 다음 질문에서 재확인 |
| 19 | 의존 범위를 안전하게 좁힐 수 없음 | 필요한 조사를 넓히거나 한계 표시; 무근거로 범위를 잘라 답하지 않음 |
| 20 | 최근 확인했지만 충돌·known change 있음 | 주기를 기다리지 않고 필요한 재확인; 정정과 대안 보존 |
| 21 | fetch한 지식의 관찰 시점이 방금 전 | 로컬 검증으로 승격하지 않으며 필요한 원본 확인 |
| 22 | 권한 거절·타임아웃·generic404·불완전 목록 | 실패 기록과 이전 성공 보존; 삭제/자료 없음으로 단정하지 않음 |
| 23 | 읽기 성공, 메모리 저장 실패/금지 | 실제 근거로 답할 수 있지만 영구 갱신 성공을 주장하지 않음 |
| 24 | A 성공, B 실패 또는 중단 | A만 완료 처리; B 성공 시각 불변; 다음 관련 질문에서 재시도 |
| 25 | 현재 상태 조회 불가 | 과거 결과로 현재를 단정하지 않고 필요한 조회/접근을 요청 |
| 26 | 연결 해제 자료 또는 과거/오프라인 요청 | 자동 재연결하지 않음; 허용한 과거 근거의 시점·한계 유지 |
| 27 | 이전 전체 갱신의 미완료 목록 존재 | 목록을 보존하되 현재 질문과 무관한 작업을 재개하지 않음 |
| 28 | 지식 갱신 성공 | 공유 저장소에 자동 게시하지 않음 |
| 29 | 두 세션이 같은 토픽을 수정 | 저장 직전 다시 읽고 정정·근거·충돌 보존; 이전 스냅샷 덮어쓰기 금지 |
| 30 | 필요한 근거가 여러 호출에서 중복 등장 | 같은 질문의 검증 결과를 재사용; 주장마다 같은 조회 반복 금지 |

실제 실행 시에는 가상 원문과 이전 기록, 도구 호출·읽은 범위, 저장 전후 파일, 답변 근거를 비교해야 합니다. 속도는 전체 처리 시간과 읽은 바이트·토큰·쓰기 횟수로 측정합니다. 검사 항목 수를 실제 AI 통과 건수로 표시하지 않습니다.
