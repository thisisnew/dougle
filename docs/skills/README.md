# 더글은 무엇인가요?

**[설치 후 자료 하나를 연결해 보세요.](install.md)**

더글은 평소 쓰는 AI에게 회사 자료를 읽고 기억하는 방법을 알려주는 스킬 모음입니다. 별도 앱을 켜거나 서버를 운영할 필요가 없습니다.

## 이렇게 씁니다

1. **연결:** 프로젝트 경로·문서 링크·DB 설명을 알려줍니다.
2. **질문:** “입하 확정 시 어느 테이블에 저장해?”처럼 물어봅니다.
3. **갱신:** 자료가 바뀌면 `dougle-reload`로 다시 읽힙니다.

정리한 지식을 팀에 보내려면 `dougle-publish`, 가져오려면 `dougle-fetch`를 사용합니다. [사용 예시](usage.md) · [팀 공유](sharing.md)

## 가능한 범위

- AI가 가진 조회 도구와 권한으로 자료를 읽습니다. 설치만으로 회사 서비스에 로그인되지는 않습니다.
- 지식은 로컬 Markdown 파일에 남습니다. 모델을 재학습시키는 방식은 아닙니다.
- 원본은 읽기만 합니다. 권한을 강제하는 장치는 아니므로 읽기 전용 계정을 사용하세요.
- 자료를 백그라운드에서 자동 감시하지 않습니다. 바뀐 자료는 갱신을 요청하세요.

현재 버전은 **0.4.0 Preview**입니다. [검증된 범위](verification.md) · [내부 구조](architecture.md)
