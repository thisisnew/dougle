# Dougle Skills

더글은 특정 AI의 전용 대화창 대신, 평소 사용하는 AI에 업무 맥락을 제공하는 스킬과 실행 도구입니다.

- `dougle-connect`: 자연어 요청에서 자료 경로·URL·DB 범위를 파악하고 연결합니다.
- `dougle-ask`: 자료와 업무 기억을 검색해 근거 기반 답변을 작성합니다.
- 두 스킬은 같은 로컬 저장소와 같은 실행 코드를 사용합니다.
- 업무 기억은 내부적으로 축적합니다. 별도 열람 화면·관리 메뉴·AI 선택 기능은 없습니다.
- 원본 코드와 회사 데이터는 읽기 전용입니다.

일반적인 흐름은 프로젝트에서 AI 실행 → connect 요청 → ask 질문 → 후속 질문/정정입니다. 연결 결과 후 선택지가 필요하면 `1 계속 연결하기`, `0 이전으로`만 제공합니다. 모델이 메뉴를 생성하거나 별도 콘솔을 실행할 필요가 없습니다.

모델에게 모든 자료를 무조건 주입하지 않습니다. 필요한 부분을 검색해 현재 AI가 읽도록 하며, 확인된 개념과 출처를 저장합니다. 저장 내용은 모델의 영구 학습이나 호스트 대화 기록 동기화가 아닙니다.
