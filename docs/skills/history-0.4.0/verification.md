# 어디까지 검증했나요?

**0.4.0은 설치·파일 구조를 검증했습니다. 실제 회사 연결과 AI 답변·병합 품질은 아직 미검증입니다.**

## 완료한 검사

| 검사 | 확인한 내용 |
|---|---|
| 구조 검사 66항목 | 참조 경로, 매니페스트, 실행 파일 부재, 배포 사본 일치 |
| 스킬 형식 검사 | 다섯 스킬의 메타데이터·형식 |
| Claude 플러그인 검사 | 플러그인·마켓플레이스 형식과 격리 환경 설치 |
| 공개 패키지 검사 | 배포 파일과 공개 다운로드의 일치 |

기록: [패키지 검사](package-verification.json) · [공개 릴리스 검사](public-release.json)

## 아직 확인하지 못한 것

- 실제 회사의 SSO 로그인과 자료 접근.
- 실제 AI의 답변 정확도·중복 판별·의미 병합 품질.
- 실제 팀의 동시 편집과 중단 후 복구 동작.

**이번 공유 기능 검증의 별도 모델 호출은 0회, 실제 사용자 지식 게시는 0건입니다.** 아래는 지침을 검토한 목록이며, 실제 AI로 전부 실행해 통과했다는 뜻이 아닙니다.
