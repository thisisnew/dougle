# 개발 — 지침 전용 스킬

정본은 skills/이며 plugins/dougle/skills/에 동일 내용을 배포합니다. 정리 프로토콜은 두 스킬에 동일하게 포함해 각각 독립 설치할 수 있습니다. 사용자용 실행 스크립트·패키지 의존성·서버·후크를 추가하지 않습니다.

개발용 구조 검사는 `node scripts/check-skills.mjs`로 실행합니다. Node는 이 검사에만 필요하며 배포물에 검사기는 포함하지 않습니다. 구조/참조/매니페스트/사본 일치를 확인할 뿐 AI의 실제 의미 품질이나 중복 판별 성공을 검증하지는 않습니다.

Claude의 `claude plugin validate ./plugins/dougle`, `claude plugin validate .`로 플러그인과 마켓플레이스를 검사합니다. 격리된 CLAUDE_CONFIG_DIR에서 로컬 등록·설치를 확인할 수 있습니다. 실제 모델 질문은 별도 평가이며 기존 호출 승인/예산을 따릅니다.

과거 실행기 코드는 Git 이력과0.2.0 릴리스에 보존합니다. 과거 사용자 데이터는 자동 삭제/이전하지 않습니다. 현재 ZIP에는 두 SKILL.md, 두 참조 문서, 호스트 플러그인 매니페스트, 설치 안내만 들어갑니다.
