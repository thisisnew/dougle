# 연결부터 공유까지

예시는 Claude 플러그인 기준입니다. Codex에서는 `/dougle:dougle-ask`를 `$dougle-ask`처럼 바꿉니다.

## 1. 자료 하나 연결하기

`연결할_URL`을 읽고 싶은 자료 링크로 바꿔 주세요.

```text
/dougle:dougle-connect 연결할_URL을 읽고 입하 업무 지식으로 정리해 줘.
```

코드 폴더나 DB도 자연어로 지정할 수 있습니다. 같은 자료를 다시 연결하면 기존 기록을 찾아 필요한 부분을 갱신합니다. [자료 연결](connections.md)

## 2. 질문하고 이어서 묻기

```text
/dougle:dougle-ask 입하 확정할 때 어느 테이블에 기록해?
그럼 어느 코드부터 보면 돼?
```

답변에는 결론과 필요한 설명, 출처가 붙습니다. 같은 대화에서는 앞선 주제를 이어받습니다. 새 세션에서는 “입하 확정 얘기인데…”처럼 주제를 알려주세요. 저장한 지식은 남아 있지만 전체 채팅이 자동으로 이어지지는 않습니다.

잘못된 설명은 “그건 예전 방식이야. 지금은 검수를 별도로 처리해”처럼 정정할 수 있습니다. 사용자 설명과 원본에서 확인한 사실은 구분해서 기록합니다.

## 3. 팀에 보내기

```text
/dougle:dougle-publish 팀_지식_저장소_URL에 입하 업무 지식을 공유해 줘.
```

선택한 지식과 근거를 팀 저장소의 내용과 합쳐 게시합니다. 민감정보가 있거나 검사를 마치지 못하면 중단합니다.

## 4. 동료의 지식 가져오기

```text
/dougle:dougle-fetch 팀_지식_저장소_URL의 지식을 가져와 합쳐 줘.
```

내 정정과 기존 근거를 보존하며 합칩니다. 이후 질문하면 필요한 원본을 확인해 답합니다. [공유와 병합](sharing.md)

Slack에서 쓰려면 `/dougle:dougle-bot`을 실행하세요. [봇 사용법](../../dougle-bot/README.md)
