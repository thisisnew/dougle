# 복사해서 쓰는 사용 예시

**어느 디렉토리에서든 사용할 수 있습니다.** 자료를 처음 등록한다면 아래 연결 요청부터 입력하세요. “현재 프로젝트”는 지금 실행한 폴더를 자료로 지정한다는 뜻이며, 다른 폴더는 그 실제 경로를 적으세요.

예시는 Claude 플러그인 기준입니다. Codex에서는 `/dougle:dougle-ask` 대신 `$dougle-ask`처럼 씁니다. Claude에 폴더로 직접 설치했다면 `/dougle-ask`처럼 씁니다.

## 1. 자료 연결하기

```text
/dougle:dougle-connect 현재 프로젝트 코드를 읽고 입하 업무를 정리해 줘.
```

문서도 연결할 수 있습니다. 아래 `[문서 URL]`을 실제 링크로 바꿔 넣으세요.

```text
/dougle:dougle-connect 이 문서도 같은 업무 자료로 참고해: [문서 URL]
```

DB는 “입하 DB의 테이블 관계를 참고해. 접근이 안 되면 필요한 설정을 알려줘.”처럼 요청하세요. **비밀번호나 토큰을 채팅에 붙여 넣지 마세요.**

같은 자료를 다시 요청하면 기존 기록을 찾아 재사용하거나 갱신합니다. [연결이 안 될 때](connections.md)

## 2. 질문하고 이어서 묻기

```text
/dougle:dougle-ask 입하 확정할 때 어느 테이블에 데이터가 들어가?
```

답변을 받은 같은 대화에서 이어서 물어보세요.

```text
그럼 어느 코드를 중점적으로 보면 돼?
```

잘못된 내용을 정정할 수도 있습니다.

```text
그건 예전 방식이야. 지금은 검수를 별도로 처리해. 기억해 줘.
```

AI는 사용자 설명과 원본에서 확인한 사실을 구분해 기록합니다. 서로 다른 내용이 있으면 숨기지 않습니다.

**새 세션에서도 저장된 지식은 읽을 수 있지만, 전체 채팅이 자동으로 이어지지는 않습니다.** “입하 확정 얘기인데…”처럼 주제를 알려주면 대상을 좁힐 수 있습니다.

답변은 **결론 → 필요한 설명 → 출처** 순서로 짧게 보여줍니다. 사실을 설명하는 문장 옆의 번호와 원본 출처를 연결합니다. 후속 질문에는 앞선 설명을 반복하지 않고 새로 물은 부분에 집중합니다. 중요한 예외나 불확실성은 생략하지 않습니다.

전체 흐름이나 자세한 코드가 필요하면 “전체 흐름을 자세히 설명해 줘”라고 요청하세요.

더글에는 답변 정리용 `i-have-adhd` 스킬이 함께 설치됩니다. Slack 초안은 함께 설치되는 숨김 `plain-language` 스킬도 호출합니다. 별도 사용자 명령은 없습니다. [답변 형식과 출처 규칙](answer-sources.md)

## 3. 자료가 바뀌었을 때

`ask`는 관련 자료의 마지막 성공한 확인이 기본 1시간 이상 지났으면 갱신 후 답합니다. 현재 상태를 묻는 질문이나 알려진 변경은 간격과 무관하게 확인합니다. “이 문서는 일주일마다 확인해 줘”처럼 주기를 바꿀 수 있습니다.

기한을 기다리지 않고 바로 갱신하려면:

```text
/dougle:dougle-reload 컨플루언스 입하 설계 문서
```

공통 저장소에 등록된 연결 자료를 모두 확인하려면:

```text
/dougle:dougle-reload 전체
```

자동 감시는 없습니다. 아직 연결하지 않은 자료라면 먼저 connect를 사용하세요. [갱신 결과 읽는 법](reload.md)

## 4. 팀에 공유하기

`our-team/domain-knowledge`를 **공유할 실제 저장소**로 바꾸세요.

```text
/dougle:dougle-publish our-team/domain-knowledge에 입하 업무 지식을 공유해.
```

원본 파일 전체 대신 정리된 업무 지식과 근거를 공유합니다. 공개 저장소라면 게시 전에 공유 내용을 확인합니다. [공유 범위](sharing.md)

## 5. 팀 지식 가져오기

```text
/dougle:dougle-fetch our-team/domain-knowledge에서 가져와 기존 지식과 합쳐줘.
```

내가 정정한 내용과 기존 근거를 보존하며 합칩니다. 내용이 충돌하면 양쪽을 남기고, 원격에서 삭제됐다고 내 지식을 자동 삭제하지 않습니다. [병합 방식](sharing.md)
