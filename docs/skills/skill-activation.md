# 답변 스킬은 어떻게 활성화하나요?

**i-have-adhd는 함께 설치되는 내부 답변 스킬입니다. Slack 답변에는 plain-language도 사용합니다.**

| 호스트 | ask의 활성화 절차 |
|---|---|
| Claude Code 플러그인 | Skill 도구로 `dougle:i-have-adhd` 호출, 성공 결과 확인 |
| Claude 개인 스킬 설치 | 등록된 `i-have-adhd`를 Skill 도구로 호출 |
| Codex | 등록된 `i-have-adhd`를 선택하고 실제 SKILL.md를 읽어 적용. 별도 Claude식 Skill 실행 도구를 가장하지 않음 |

**ask를 호출할 때마다 동반 스킬 활성화를 확인합니다.** Claude에서는 해당 질문의 성공한 Skill 결과가 필요합니다. 이전 대화의 활성화 기록이나 세션 복원만으로 생략하지 않습니다. Codex에서는 이번 질문에 적용할 실제 독립 스킬을 로드합니다. 사용자가 형식을 끄면 이후 ask마다 자동으로 다시 켜지 않습니다. 미설치·권한 거부·호출 실패는 알리고 기본 간결한 답변으로 계속합니다. 차단된 스킬을 다른 경로로 읽어 우회하지 않습니다.

## 원본에서 바뀐 부분

원본 i-have-adhd에는 `disable-model-invocation: true`가 있습니다. 더글 배포본은 ask에서 호출할 수 있도록 해당 금지 설정을 제거하고, 더글 답변·후속 질문에 적용하는 범위를 명시했습니다. 진단을 추정하거나 출처·중요 예외를 삭제하지 않습니다. 원본 규칙 본문과 MIT 라이선스를 보존하며, 수정 없는 원본 스냅샷도 ask/references에 남깁니다.

더글 설치에 함께 포함되며 사용자가 별도로 실행할 필요가 없습니다. ask가 답변 전에 내부에서 호출합니다. Claude에서는 `user-invocable: false`로 명령 목록에서 숨기고 AI 호출은 허용합니다. Codex의 목록 표시 방식은 호스트에 따라 다르며 이 Claude 설정만으로 숨김을 보장하지 않습니다. 단순히 이름을 출력한 것은 호출 성공이 아닙니다.

## 확인한 근거

- [Claude 공식 스킬 문서](https://code.claude.com/docs/en/skills): 모델의 Skill 도구 호출, 호출 제한 설정, 플러그인 이름 구분.
- [OpenAI 공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills): 등록된 스킬의 선택과 지침 로딩 방식.

## 이전 검증 기록

과거 호스트 버전에서 수행한 [활성화 검사 결과](activation-verification.json)는 당시 기록입니다. 현재 회사 환경의 호출 성공을 보장하지 않습니다.

## 존댓말과 봇 검증

더글이 작성하는 설명·목록·후속 질문·오류·Slack 초안은 항상 존댓말을 사용합니다. 가독성 모드를 꺼도 이 규칙은 유지됩니다. 인용문과 코드는 원문을 보존합니다.

일반 ask는 호스트 AI가 스킬을 실행하고 최종 문장을 검토하는 방식입니다. 모델의 모든 출력을 가로채는 필터는 아닙니다. 선택형 봇 런타임은 매 호출에서 dougle-ask·i-have-adhd·plain-language의 Skill 도구 성공 기록을 확인하고, 알려진 반말 표현을 별도로 검사합니다. 누락·실패하면 한 번 재작성시키고, 재실패 시 승인용 초안을 만들지 않습니다. 이름을 언급하거나 참고 파일을 읽은 것만으로 Claude Skill 실행을 인정하지 않습니다.

가짜 CLI·Slack과 임시 SQLite로 실행 기록과 실패 처리를 검사합니다. 이는 실제 회사 Claude의 호출·답변 품질을 확인한 결과와 구분합니다.
