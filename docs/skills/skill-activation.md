# 답변 스킬은 어떻게 활성화하나요?

`i-have-adhd`는 더글과 함께 설치되는 내부 답변 정리 스킬입니다. Slack 답변에는 `plain-language`도 적용합니다.

| 호스트 | ask의 활성화 절차 |
|---|---|
| Claude Code 플러그인 | Skill 도구로 `dougle:i-have-adhd`를 호출하고 성공 결과 확인 |
| Claude 개인 스킬 | 등록된 `i-have-adhd`를 Skill 도구로 호출 |
| Codex | 등록된 `i-have-adhd`를 선택하고 실제 `SKILL.md`를 읽어 적용 |

ask마다 이번 질문에 필요한 활성화를 확인합니다. Claude는 성공한 Skill 결과가 필요하며 이전 대화의 실행이나 세션 복원만으로 생략하지 않습니다. Codex는 실제 스킬 지침을 로드하며 Claude식 호출 도구가 있다고 가정하지 않습니다. 목록에 없으면 호스트 탐색이나 설치 경로에서 실제 스킬을 확인한 뒤 로드합니다. 이 방식은 목록 등록이나 Claude식 호출 성공을 뜻하지 않습니다.

사용자가 답변 정리 형식을 끄면 다음 ask에서 임의로 다시 켜지 않습니다. 일반 ask에서 미설치·권한 거부·호출 실패가 생기면 이를 알리고 간결한 기본 답변으로 계속합니다. 차단을 다른 경로로 우회하거나 이름을 출력한 것만으로 성공 처리하지 않습니다.

## 원본에서 바뀐 부분

더글 배포본은 원본의 `disable-model-invocation: true`를 제거해 ask가 호출할 수 있도록 구성합니다. 적용 범위는 더글 답변·후속 질문이며 진단을 추정하거나 출처·중요 예외를 삭제하지 않습니다. 원본 규칙 본문·MIT 라이선스와 수정 없는 원본 스냅샷을 ask/references에 보존합니다.

사용자가 따로 실행할 필요는 없습니다. Claude에서는 `user-invocable: false`로 명령 목록에서 숨기고 AI 호출은 허용합니다. Codex의 표시 방식은 호스트에 따라 다르므로 이 설정만으로 숨김을 보장하지 않습니다.

## 확인한 근거

- [Claude 공식 스킬 문서](https://code.claude.com/docs/en/skills): Skill 호출, 호출 제한, 플러그인 이름 구분.
- [OpenAI 공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills): 등록된 스킬 선택과 지침 로딩.

## 이전 검증 기록

[활성화 검사 결과](activation-verification.json)는 당시 호스트 버전에서 수행한 기록입니다. 현재 회사 환경의 호출 성공을 보장하지 않습니다.

## 존댓말과 봇 검증

더글의 설명·목록·후속 질문·오류·Slack 답변은 존댓말을 사용합니다. 답변 정리 형식을 꺼도 이 규칙은 유지되며 인용문과 코드는 원문을 보존합니다.

일반 ask는 호스트 AI가 지침을 적용하고 최종 문장을 검토합니다. 봇 런타임은 매 엔진 호출에서 `dougle-ask`·`i-have-adhd`·`plain-language`의 Skill 성공 기록과 알려진 반말 표현을 검사합니다. 누락·실패하면 한 번 재작성하고 재실패하면 게시 가능한 답변으로 처리하지 않습니다. 이름 언급이나 참고 파일 읽기는 Claude Skill 실행 성공을 대신하지 못합니다.

이 검사는 기본 자동 게시와 명시적 검토 모드 모두에 적용합니다. 가짜 CLI·Slack과 임시 SQLite로 실행 기록·실패 처리를 검사한 결과는 실제 회사 Claude의 호출·답변 품질과 구분합니다.
