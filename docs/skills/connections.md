# 자유로운 자료 연결

자료 종류를 메뉴에서 고르지 않습니다. 사용자가 링크·경로·설명을 주면 호스트 AI가 해당 자료를 읽을 수 있는 도구를 찾습니다. 컨플루언스·노션·DB·웹·코드 등은 예시이며 고정 허용 목록이 아닙니다.

## 연결이 안 될 때

- 조회 도구가 없음: 사용 가능한 커넥터/MCP 설정 경로를 확인해 안내.
- 로그인 필요: 호스트의 해당 인증 흐름 안내.
- 자료 권한 없음: 접근할 수 없는 대상과 필요한 권한 설명.
- 자료 없음/일시 오류: 실제 응답에 따라 구분. 무조건 재로그인시키지 않음.

원래 요청과 미완료 단계를 pending 기록으로 남기고 설정 후 같은 자료 읽기를 재개합니다. 토큰/비밀번호를 채팅에 요구하거나 도구 이름·설정 명령을 지어내지 않습니다. 자료 요청만으로 커넥터 설치나 권한 확대를 자동 승인하지 않습니다.

## 중복은 더글이 확인

같은 자료는 재사용하고, 변경됐다면 기존 기록을 갱신합니다. 사용자는 등록 여부를 신경 쓰지 않아도 됩니다.

| 자료 | 동일성 기준 |
|---|---|
| 로컬 | 실제 절대 경로. 이미 연결한 폴더 안 파일은 기존 연결의 확인 범위 확장 |
| 컨플루언스 | 확인된 회사 사이트 + 페이지 ID. 제목 변경/공유 URL은 별칭 |
| 노션 | 확인된 작업 공간/계정 범위 + 페이지/DB ID |
| 일반 웹 | 읽기 도구가 확인한 정규 URL. 의미 있는 쿼리는 유지 |
| DB | 확인된 서버/인스턴스·DB·스키마 범위. 프로필명만으로 합치지 않음 |

내용이 같은 다른 출처는 자동 병합하지 않습니다. 동일성을 확정할 정보가 없을 때만 필요한 확인을 요청합니다. 정확히 같은 pending 요청도 새 레코드를 반복 생성하지 않습니다. 변경 없음은 실제 버전/내용 확인 후에만 말합니다.

이는 스킬 절차이며 원자적 고유키 제약이 아닙니다. 같은 작업 공간의 등록은 순차 수행하고 쓰기 전에 최신 파일을 다시 읽습니다.

연결 후 선택지가 필요하면 `1 계속 연결하기`, `0 이전으로`만 제공합니다. 별도 UI·지식 열람·AI 선택 메뉴는 없습니다.
