# 자료 연결하기

**원하는 자료와 읽을 범위를 알려주세요.** 실행 폴더와 관계없이 같은 로컬 지식에 정리합니다.

```text
/dougle:dougle-connect 연결할_URL을 읽고 회송 업무를 정리해 줘.
```

`연결할_URL`에는 문서나 저장소 링크를 넣습니다. “현재 프로젝트와 이 문서를 함께 읽어 줘”, “입하 DB의 테이블 관계를 정리해 줘”처럼 요청해도 됩니다.

## 연결한 뒤 남는 것

| 기록 | 내용 |
|---|---|
| 토픽 | 업무 개념, 규칙, 조건·예외, 시스템 관계 |
| 소스 | 실제 원본 위치, 읽은 범위, 확인 시점·버전 |
| 목차 | 주제·동의어·식별자로 지식을 찾는 안내 |

자료 일부만 읽었다면 그 범위만 기록합니다. 양이 많으면 나눠 읽고 완료·미완료 범위를 남겨 이어갑니다. [대용량 처리](large-corpus.md)

## 연결이 막히면

| 확인된 문제 | 다음 행동 |
|---|---|
| 조회 도구가 없음 | 안내된 커넥터·MCP를 설정합니다. |
| 로그인 필요 | 해당 서비스에 로그인합니다. |
| 읽기 권한 없음 | 요청한 자료의 읽기 권한을 확인합니다. |
| 자료 없음·일시 오류 | 주소와 서비스 상태를 확인합니다. |

준비가 끝나면 “아까 연결하던 자료 이어서 읽어 줘”라고 요청하세요. 비밀번호나 토큰을 채팅에 붙여 넣지 않습니다.

## 같은 자료를 다시 연결하면

기존 자료의 실제 경로·사이트와 페이지 ID·DB 범위를 비교해 기록을 재사용합니다. 제목만 같은 자료는 별개로 둡니다. 중단된 연결도 기존 요청에서 이어갑니다.
