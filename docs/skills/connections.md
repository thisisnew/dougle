# 자료 연결과 지원 범위

사용자는 종류를 고르는 메뉴 대신 "현재 폴더와 이 링크를 연결해"라고 요청합니다. 스킬이 의도를 해석하고 코드가 처리합니다. 모호한 대상과 필요한 인증만 추가로 묻습니다.

## 로컬

파일·폴더의 UTF-8 코드/텍스트를 읽어 최대4,000자 단위로 색인합니다. Gradle·Java·SQL·Markdown 등 텍스트를 실행하지 않고 읽습니다. 숨김·빌드·의존성 폴더, 심볼릭 링크, 일부 비밀정보 파일을 제외합니다. 검색 전 변경/삭제를 반영하며 파일을 못 읽으면 이전 본문을 최신으로 돌려주지 않습니다.

현재 한도: 파일8MiB, 스캔128MiB, 방문 파일10,000개. 큰 텍스트도 한도 내에서 청크로 나누며 초과하면 이유와 partial 상태를 반환합니다. 무제한 대형 파일·PDF/OCR·모든 인코딩 지원은 아닙니다. 제외된 바이너리는 처리 실패로 위장하지 않지만 필요한 자료가 빠졌다면 답변 한계를 알려야 합니다.

## 컨플루언스와 웹

1. URL을 등록하면 pending입니다.
2. 현재 AI에 제공된 인증된 읽기 도구로 그 페이지를 읽습니다.
3. 실제 도구 결과를 출처·수집 시점과 함께 capture합니다.
4. 상태는 snapshot입니다. 새 질문에 최신 정보가 필요하면 원본을 다시 조회합니다.

읽기 도구가 없거나 권한이 없으면 pending으로 남깁니다. 회사 SSO/브라우저 쿠키/OAuth를 우회하지 않습니다. 더글은 원격 HTTP를 직접 실행하지 않으며, capture의 원본 조회 여부는 호스트 도구 호출과 스킬이 책임집니다. 임의 문자열을 넣을 수 있는 내부 API를 독립적인 진위 검증으로 표현하지 않습니다.

## DB

SQLite는 mode=ro, query_only, 제한된 생성 쿼리, authorizer로 읽습니다. 스키마를 저장하고 실제 행은 명시된 테이블에서 제한 조회합니다. 뷰/임의 SQL/프로시저/확장 로딩을 제공하지 않습니다. 행 조회 결과는 저장하지 않습니다.

MySQL/PostgreSQL 같은 회사 DB는 현재 AI의 읽기 전용 연결을 사용합니다. `db://profile/database`는 비밀정보 없는 범위 식별자이며 접속 문자열이 아닙니다. 구조와 관계를 snapshot으로 저장할 수 있지만 실제 조회는 호스트 도구가 수행합니다. 계정 자체에도 읽기 전용 권한을 적용해야 합니다. 새 드라이버·SSH 터널·IAM 인증 자동 설정은 내장하지 않았습니다.

## 내부 도구

정확한 JSON 스키마와 명령은 [실행 계약](../../skill-runtime/tools.md)을 따릅니다. connect/capture/search/remember/status/forget/rows가 있으며 status는 진단 도구이지 별도의 사용자 메뉴가 아닙니다. 원본 쓰기 명령은 없습니다.
