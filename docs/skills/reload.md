# 바뀐 자료 갱신하기

**이미 연결한 자료를 다시 읽히려면 `dougle-reload`를 쓰세요.**

```text
/dougle:dougle-reload 컨플루언스 입하 설계 문서
```

현재 프로젝트나 전체 연결 자료도 지정할 수 있습니다.

```text
/dougle:dougle-reload 현재 프로젝트
/dougle:dougle-reload 전체
```

Codex에서는 `$dougle-reload`, 개인 폴더로 설치한 Claude에서는 `/dougle-reload`를 사용합니다.

## 어디까지 갱신하나요?

`전체`는 **현재 작업 공간에 연결된 자료**를 뜻합니다. 다른 작업 공간이나 회사 전체를 새로 수집하지 않습니다. 연결 대기 중인 자료는 접근 가능해졌는지도 확인합니다.

처음 등록하는 자료는 [connect](connections.md)로 연결하세요. 서비스 이름·문서 이름·경로로 대상을 지정할 수 있습니다.

## 결과 읽는 법

| 결과 | 뜻 |
|---|---|
| 변경·변경 없음·재확인 | 현재 원문을 읽었습니다. 비교 기준이 없으면 “변경 없음” 대신 “재확인”으로 구분합니다. |
| 부분 처리 | 일부만 읽었습니다. 남은 범위를 함께 알려줍니다. |
| 접근 실패 | 읽지 못했습니다. 마지막 성공 시점을 유지하며 최신 정보라고 취급하지 않습니다. |
| 삭제 확인 | 삭제됐다는 근거를 확인했습니다. 권한 오류만으로 삭제를 판단하지 않습니다. |
| 미처리 | 아직 읽지 않았거나 중단됐습니다. 완료 건수에 넣지 않습니다. |

## 중간에 실패했다면

1. 안내된 연결·권한 문제를 해결합니다.
2. 같은 대상으로 `dougle-reload`를 다시 요청합니다.

완료된 기록은 남기고 미완료 범위부터 재확인합니다. 사용자 정정과 새 원문이 다르면 양쪽 근거를 구분해 보존합니다. 원본 코드·문서·DB는 수정하지 않습니다.

**자동 갱신은 없습니다.** 질문할 때 필요한 근거도 확인하지만, 연결 자료 전체를 다시 정리하려면 reload를 요청하세요.
