# 연결 자료 갱신

Claude 플러그인 설치에서는 다음처럼 요청합니다.

```text
/dougle:dougle-reload 현재 프로젝트
/dougle:dougle-reload 컨플루언스 입하 설계 문서
/dougle:dougle-reload 전체
```

Codex에서는 `$dougle-reload`를 선택하고 대상을 적습니다. 개인 폴더로 설치한 Claude에서는 `/dougle-reload`입니다. 서비스 이름·자료 이름·경로·자료 ID로 기존 연결을 찾으며 모호할 때만 확인합니다. 등록되지 않은 자료는 먼저 connect가 필요합니다.

`전체`는 현재 작업 공간에서 연결 해제하지 않은 자료를 기존 권한 범위 안에서 확인하는 뜻입니다. 다른 작업 공간이나 회사 전체를 새로 수집하지 않습니다. 대기 상태였던 자료도 접근 가능해졌는지 확인합니다.

## 결과 구분

- 변경: 바뀐 원문을 읽고 관련 주장/관계만 갱신.
- 변경 없음: 비교 가능한 버전·내용을 실제 확인했을 때만 표시.
- 재확인: 비교 기준이 없어 동일성을 확정할 수 없지만 현재 근거를 다시 읽은 경우.
- 부분 처리: 일부만 읽은 범위와 남은 자료를 표시.
- 접근 실패: 기존 관찰 시점은 유지하고 현재 근거로 쓰지 않도록 표시. 필요한 호스트 설정 안내.
- 삭제 확인: 확실한 근거가 있을 때만 표시. 권한 오류를 숨기는404나 불완전한 목록만으로 삭제 판정하지 않음.
- 미처리: 중단되거나 아직 읽지 않은 대상. 완료 건수에 포함하지 않음.

자료별 마지막 시도와 성공한 확인 시점을 구분합니다. 중단 전 완료된 기록은 보존하고 나머지부터 재확인합니다. 사용자 정정과 충돌하는 원문은 서로 구분해 남기며 정정을 조용히 덮어쓰지 않습니다. 원본 코드·문서·DB를 변경하지 않습니다.

독립 실행기나 백그라운드 감시는 없습니다. 호스트 AI가 스킬 절차를 수행합니다. ask도 답변에 필요한 최신 근거는 확인하지만 전체 자료의 재정리는 reload로 명시적으로 실행합니다.
