# 질문하면 필요한 지식만 갱신합니다

**별도 갱신 명령 없이 평소처럼 질문하세요.**

1. 질문에 필요한 자료와 근거를 찾습니다.
2. 원본의 버전·내용이 바뀌었는지 확인합니다.
3. 변경이 없으면 근거를 재사용합니다. 바뀌었다면 필요한 원문·관련 관계를 읽고 해당 지식만 고칩니다.
4. 확인한 근거와 출처로 답합니다.

자료500개가 바뀌었어도 질문에 필요한 것이3개라면, 그3개와 필요한 연관 근거를 먼저 확인합니다. 나머지는 최신으로 표시하지 않습니다. 실제 구현·오류 원인·현재 DB 상태를 묻는 질문에서는 필요한 직접 조회를 생략하지 않습니다.

## 항상 감시하는 건가요?

아닙니다. 질문하는 동안 필요한 범위를 확인합니다. 질문하지 않은 자료는 기존 상태로 남으며, 세션을 닫은 뒤 자동 작업이나 공유는 실행하지 않습니다. 자료의 출처·주장·조건·예외는 계속 보존합니다.

## 기존 설정은 어떻게 되나요?

기본은 **관련 질문마다 확인**입니다. 사용자가 지정한 자료별 → 기존 자료 묶음 → 공통 확인 주기는 그대로 우선합니다. 출처가 불분명한 옛 설정도 임의 변경하지 않습니다.

주기를 바꾸고 싶다면 ask에서 자연어로 요청하세요.

```text
이 자료는 질문할 때마다 확인해 줘.
이 문서는 일주일마다 확인해 줘.
```

현재 상태 질문·알려진 변경·충돌·확인되지 않은 근거는 주기가 남아 있어도 필요한 확인을 수행합니다. 과거 기준이나 오프라인 답변을 요청하면 해당 시점의 근거로 설명하고 현재 확인으로 표시하지 않습니다.

## 읽거나 저장하지 못했다면

- 권한·연결 오류는 마지막 성공 기록을 유지하고 실제 문제를 안내합니다.
- 일부만 확인했다면 그 부분만 기록합니다. 전체 자료가 최신이라고 표시하지 않습니다.
- 원문을 읽었지만 저장하지 못했다면 이번 답변에는 실제 근거를 사용할 수 있으나 저장 완료로 말하지 않습니다.
- 다음 관련 질문에서 다시 확인하며, 한 질문 안에서 실패한 조회를 무한 반복하지 않습니다.

기존 지식·연결·확인 기록은 그대로 사용합니다. 과거 전체 갱신의 미완료 목록이 있어도 질문과 무관한 작업까지 재개하지 않습니다.
