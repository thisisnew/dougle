# 질문할 때 필요한 지식을 갱신합니다

**평소처럼 질문하시면 됩니다.** 별도 자료 갱신 명령은 없습니다.

| 확인 결과 | 처리 |
|---|---|
| 원본이 그대로이고 근거가 충분함 | 확인한 지식을 재사용합니다. |
| 원본이 바뀜 | 질문에 필요한 변경과 관련 조건·근거를 읽고 갱신합니다. |
| 설명이 부족하거나 서로 충돌함 | 검색 범위를 넓혀 원본을 확인합니다. |
| 실제 코드 동작을 물음 | 관련 구현과 호출 조건을 직접 확인합니다. |
| 현재 DB·운영 상태를 물음 | 해당 환경의 최신 값을 조회합니다. |

질문과 무관한 자료까지 모두 갱신할 때까지 기다리지 않습니다. 질문하지 않은 자료는 기존 상태로 남습니다.

## 확인 주기

기본은 관련 질문마다 변경 확인입니다. 사용자가 지정한 주기는 자료별, 기존 자료 묶음, 공통 설정 순서로 적용합니다.

```text
이 자료는 질문할 때마다 확인해 줘.
이 문서는 일주일마다 확인해 줘.
```

현재 상태, 알려진 변경, 충돌, 미확인 근거는 주기가 남아 있어도 확인합니다. 과거 시점이나 오프라인 답변을 요청하면 그 범위의 근거로 설명합니다.

## 확인이 끝나지 않았다면

읽기 실패는 마지막 성공 기록을 바꾸지 않습니다. 일부만 확인했으면 그 부분만 기록합니다. 원본을 읽었어도 저장에 실패하면 저장 완료로 표시하지 않습니다. 한 질문 안에서 실패한 조회를 무한 반복하지 않습니다.
