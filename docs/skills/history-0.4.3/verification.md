# 어디까지 검증했나요?

**0.4.3은 설치·파일 구조를 검증했습니다. 실제 회사 연결과 AI 답변·병합 품질은 아직 미검증입니다.**

|---|---|

기록: [패키지 검사](package-verification.json) · [공개 릴리스 검사](public-release.json)

## 0.4.1의 변경

ask에 짧은 기본 답변, 결론 우선, 주장 옆 출처, 후속 질문 반복 생략 지침을 추가했습니다. 상세 설명 요청과 중요한 예외·불확실성은 유지합니다. 외부 가독성 스킬이나 실행 의존성을 추가하지 않았습니다.

[답변 가독성 평가 시나리오](../answer-readability.md)는 실제 모델 평가 때 사용할 기준입니다. 이번에는 지침 검토와 구조·형식 검사를 수행했으며, 모델을 호출해 답변 품질을 평가하지 않았습니다.

## 0.4.2의 변경

ask 실행 시 기본 24시간 경과를 확인해 관련 자료를 갱신하는 지침을 추가했습니다. 자료별 주기, 범위별 성공 시각, 변경·실패·부분 처리·가져온 지식의 재확인 규칙을 공통 프로토콜에 반영했습니다. 예약 실행기는 없습니다.

[갱신 평가 시나리오](../freshness-evaluation.md)는 경계·오류 상황별 기대 동작입니다. 구조 검사와 지침 검토는 수행하지만 실제 모델 출력으로 이 시나리오를 실행한 것은 아닙니다.

## 0.4.3의 변경

ask가 i-have-adhd 원본 지침을 읽도록 하고 원본과 MIT 라이선스를 함께 배포합니다. 검색은 주제·동의어 목차, 정확한 원본 위치, 독립 조회 묶기를 우선합니다. 업무 답변에는 주장과 연결된 원본 출처를 표시하도록 강화했습니다.

구조 검사에는 외부 지침·라이선스의 고정 해시 검증이 포함됩니다. 실제 모델의 형식 준수·출처 정확성·검색 지연 시간 개선은 별도 측정이 필요합니다. [평가 시나리오](../answer-readability.md)

## 아직 확인하지 못한 것

- 실제 회사의 SSO 로그인과 자료 접근.
- 실제 AI의 답변 정확도·중복 판별·의미 병합 품질.
- 실제 팀의 동시 편집과 중단 후 복구 동작.

**이번 공유 기능 검증의 별도 모델 호출은 0회, 실제 사용자 지식 게시는 0건입니다.** 아래는 지침을 검토한 목록이며, 실제 AI로 전부 실행해 통과했다는 뜻이 아닙니다.
