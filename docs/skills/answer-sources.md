# 답변과 출처

**일반 ask 답변의 업무 사실에는 확인한 원본 출처를 붙입니다.** 추론은 추론이라고 표시하고 그 근거를 함께 보여줍니다.

## 말투

더글의 한국어 답변은 존댓말을 사용합니다. 질문을 반말로 하셔도 설명·후속 질문·오류 안내·Slack 초안은 같은 말투를 유지합니다. 원문 인용과 코드는 그대로 보존합니다. 답변 정리 모드를 끄더라도 존댓말 규칙은 유지됩니다.

본문의 번호는 아래 출처와 대응합니다. 호스트가 본문 안에 직접 링크를 붙이는 방식을 요구한다면 같은 출처를 아래에 또 반복하지 않습니다.

## 어떤 출처를 보여주나요?

| 자료 | 표시할 내용 |
|---|---|
| 컨플루언스·노션·웹 | 문서 제목, 실제 확인한 원본 URL, 필요한 절 |
| 코드·로컬 문서 | 실제 파일 경로와 확인한 함수·행 위치 |
| DB | 비밀정보 없는 연결 이름, 스키마·테이블, 조회 시각과 가능한 조회 식별자 |
| 이전 기억·가져온 지식만 있음 | 기록된 원본 위치와 관찰 시점. 직접 원본을 재확인하지 못했다는 설명 |
| 사용자 설명 | 사용자에게 들은 내용으로 표시. 원본 확인 사실과 구분 |

검색에 걸렸다는 이유로 무관한 문서를 붙이지 않습니다. 확인하지 않은 URL·행 번호를 만들거나 토큰이 붙은 주소를 노출하지 않습니다. 출처를 찾지 못한 주장은 확인 불가로 남깁니다.

## 가독성 기본값

`i-have-adhd`는 별도 스킬 폴더로 함께 설치됩니다. Claude에서 ask는 Skill 도구로 `dougle:i-have-adhd`를 호출하도록 연결되어 있습니다. Codex는 등록된 스킬을 선택하고 실제 SKILL.md를 읽는 방식으로 활성화합니다.

호출 실패·미설치를 성공으로 표시하지 않습니다. [호스트별 호출 방식과 검증 범위](skill-activation.md)

## Slack 봇 답변

게시 본문은 질문의 핵심·영향·필요한 행동을 쉬운 존댓말로 설명합니다. 출처 목록·인용 번호·서명은 붙이지 않고, 근거는 승인자 DM과 저장된 초안에 남깁니다. `i-have-adhd`와 `plain-language`를 함께 호출하며 필요한 조사나 조건·불확실성을 생략하지 않습니다. [봇 사용법](../../dougle-bot/README.md)
