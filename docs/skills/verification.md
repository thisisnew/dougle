# 검증 범위

**0.8.14 / 봇0.1.11은 터미널 진행 로그와 운영 조회 확인 요청을 개선합니다.**

문의별 관측 단계·경과 시간·마지막 신호·최종 상태를 기록합니다. 새 검사12개는 원문 노출 방지, 동시 기록, 파일 용량 제한, 심볼릭 링크 차단, 기록 실패 시 응답 지속, 구버전 통계 호환을 확인합니다. 전체 결과는 [패키지 검증](package-verification.json)에 기록합니다.

[터미널 모니터링 사용법](../../dougle-bot/README.md#터미널에서-진행-상황-보기) · [직전 조회 기록 수정](../dougle-bot/receipt-verification-fix.md) · [시나리오 평가와 한계](../scenarios/execution-20261107/README.md)

자동 테스트647개가 통과했습니다. 운영 조회 관련 새 검사21개는 시간 없는 결과 제출·같은 문의의 답변 재개, SQL 제외 후 확인 요청 유지, 짧은 답변의 근거 누락 차단과 정상 게시, DM 서식을 확인합니다. 기존 시간 필수 검사1개는 새 계약에 맞춰 대체했습니다.

실제 Codex1회에 합성 BigQuery MCP2사례를 연결해, 도구 탐색→스키마→집계 조회와 권한 거부 후 내부 요청을 확인했습니다. [실제 모델 검사 기록](../dougle-bot/operational-lookup-verification.json)에 호출·토큰 사용량과 범위를 기록합니다. 이 검사는 회사 BigQuery 연결이나 native Claude 실행을 검증한 것이 아닙니다. 회사 서비스 성공이나 실제 AI 응답 시간을 보장하지 않습니다.
