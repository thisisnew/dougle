# 0.4.0 검증 범위

구조 검사66항목과 다섯 스킬의 skill-creator 형식 검사가 통과했습니다. 공통 정리/공유 프로토콜 사본과 플러그인 배포 파일 일치, 상대 참조, 매니페스트, 실행 파일 부재를 확인합니다. Claude의 플러그인·marketplace 검증 및 격리 설치 확인을 수행합니다. 이는 실제 AI의 의미 병합 정확도 검사가 아닙니다.

## 공유 절차 검토 항목

- 대상 미지정, 공개/비공개/공개범위 불명, 자격 증명 없는 상태.
- 개인 경로·원본·DB 행·비밀정보·전체 대화가 포함된 내보내기.
- 서로 다른 PC 경로와 같은 팀 프로젝트 ID의 매핑.
- 최초 fetch(기준점 없음), 같은 버전 반복, 로컬만 변경, 원격만 변경.
- 양쪽 보완 정보, 모순된 주장, 로컬 사용자 정정 충돌, 원격 삭제.
- 같은 S001이 서로 다른 저장소/프로젝트에서 온 경우.
- 오래된 원격 관찰, 실제 원본 접근 권한이 없는 수신자.
- 악의적 원격 지시, 경로 탈출, 심볼릭 링크, 미지원 형식, 깨진 근거 링크.
- 가져오기 중 로컬 수정, 일부 파일 저장 후 중단, 체크포인트 실패.
- push 직전 원격 변경, 거절된 push, 업로드 후 응답 유실, 원격 전용 추가 내용 보존.

위 항목은 프로토콜에 대한 검토 목록입니다. 실제 호스트 모델의 행동을 자동 실행하여 모두 통과했다는 뜻이 아닙니다. 별도 모델 호출0회, 실제 사용자 지식 게시0건. 지정된 회사 지식 저장소가 없으며 회사 SSO/자료 접근, 실제 팀 동시 편집과 의미 병합 품질은 미검증입니다.

[이전0.3.1 기록](history-0.3.1/verification.md)은 당시 스킬 버전에 대한 기록입니다. 과거 Python 실행기의 테스트 수치를 합산하지 않습니다. 공개 패키지 검증 결과는 package-verification.json/public-release.json에 기록합니다.
