# 검증 범위

**0.8.12는 시나리오 평가에서 발견한 지침 충돌과 대량 자료 검사 병목을 보완한 버전입니다.** 선택형 봇 실행기는0.1.9를 유지합니다.

- 봇 자동 테스트597개 통과.
- 실제 AI 호출181회로 합성 자료·격리 도구·행동 선택을 평가했습니다.
- 민감정보 빠른 경로와 기존 경로 각각84개 통과, 200개 입력 비교와10만 파일 검사 완료.
- 스킬 구조280항목, 병합 판단64조합·로컬 Git 전송6개, 배포 파일 일치를 확인했습니다.

1,066개 전체 시나리오의 종단간 통과를 뜻하지 않습니다. 실제 회사 연결은 확인하지 않았고 Claude CLI는 인증 만료로 실행 검증이 막혔습니다. 판단 평가와 파일 작업 측정도 실제 제품 전체 실행과 구분합니다.
