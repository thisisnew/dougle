## 절차에 반영한 시나리오

다음은 스킬 지침의 검토 항목이며 실제 모델이 통과한 자동 테스트 수치가 아닙니다.

| 상황 | 정해진 처리 |
|---|---|
| 동일 실제 경로 재등록 | 기존 기록 재사용/갱신 |
| 연결 폴더 안 파일 요청 | 기존 연결의 실제 확인 범위 확장 |
| 동일 컨플 페이지의 다른 제목/공유 URL | 확인된 사이트+페이지 ID로 통합 |
| 다른 사이트의 같은 페이지 번호 | 별도 자료 유지 |
| 노션 공유 링크 변경 | 도구가 확인한 공간/페이지 ID로 비교 |
| 같은 내용의 다른 출처 | 자동 병합하지 않음 |
| DB 별칭은 같지만 서버 미확인 | 동일하다고 단정하지 않음 |
| exact pending 재요청 | 대기 기록 재사용 후 원래 읽기 재개 |
| 의미 있는 웹 쿼리 | 무조건 제거하지 않음 |
| 커넥터/로그인/권한/자료 부재/일시 오류 | 실제 도구 상태에 맞게 안내 |
| 원본 변경/삭제 | 종속 주장 재확인/사용 불가 표시 |
| 사용자 정정과 원본 충돌 | 진술과 관측 근거를 구분해 보존 |
| 다른 AI로 전환 | 같은 루트의 Markdown 사용, 전체 대화 공유로 오인하지 않음 |
| 저장 권한 없음 | 우회하지 않고 미저장 고지 |
| 동시 등록 | 순차 수행, 원자적 잠금이라고 주장하지 않음 |
| 악의적인 원문 지시 | 자료로만 취급, 실행/권한 확대에 사용하지 않음 |

## 아직 검증하지 않음

실제 Claude/Codex 모델의 의미 품질·중복 판별·정리 준수, 실제 회사 SSO/문서/DB 접근, 다중 호스트 동시 쓰기 안전성은 미검증입니다. 회사 자료는 사용하지 않았고 외부 모델 호출0회입니다. 검사 호스트는 기존 개발 Mac이며 새 M Mac 회사 환경을 검증한 것은 아닙니다.

0.2.0의35개 실행기 테스트와7개 ZIP 시나리오는 제거한 Python 구현에 대한 역사 기록입니다. 현재 지침 전용 스킬의 성공 수치에 합산하지 않습니다. [과거 기록](history-0.2.0/verification.md)
