**0.8.3은 질문 범위에 맞춘 답변 정책과 Slack PNG/JPEG 이미지 전달을 추가합니다. 일반 ask의 출처와 승인 절차는 유지합니다.**

[가상 질문·이미지 평가](../dougle-bot/answer-evaluation/README.md): 실제 Codex CLI1회로14문항을 평가했습니다. 문자열·길이 기준14/14, 수동 범위 검토12/14였고2개는 지침을 추가 보완했습니다. 최종 추가 문구의 모델 재평가와 실제 회사 Claude 이미지 연동은 미실행입니다. 외부 모델 호출 누계200/200입니다.

## 0.4.1의 변경

ask에 짧은 기본 답변, 결론 우선, 주장 옆 출처, 후속 질문 반복 생략 지침을 추가했습니다. 상세 설명 요청과 중요한 예외·불확실성은 유지합니다. 외부 가독성 스킬이나 실행 의존성을 추가하지 않았습니다.

[답변 가독성 평가 시나리오](answer-readability.md)는 실제 모델 평가 때 사용할 기준입니다. 이번에는 지침 검토와 구조·형식 검사를 수행했으며, 모델을 호출해 답변 품질을 평가하지 않았습니다.

## 0.4.2의 변경

[갱신 평가 시나리오](freshness-evaluation.md)는 경계·오류 상황별 기대 동작입니다. 구조 검사와 지침 검토는 수행하지만 실제 모델 출력으로 이 시나리오를 실행한 것은 아닙니다.

## 0.4.3의 변경
