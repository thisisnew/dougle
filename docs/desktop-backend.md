# 설치형 앱의 로컬 서버 보호

설치형 준비를 위해 백엔드에 **앱 실행마다 바뀌는 세션 인증**과 종료 감시를 추가했습니다.
이 문서는 서버 준비 단계입니다. 이것만으로 Mac 설치 앱이 완성된 것은 아닙니다.

## 실행 약속

- 기본 개발 모드는 기존과 같습니다.
- 네이티브 호스트가 `FORGE_DESKTOP=true`, 절대 경로 `FORGE_DATA_DIR`를 지정합니다.
- 실행 인자나 URL이 아닌 stdin 첫 줄로 64자리 무작위 16진 토큰을 전달하고 파이프를 열어 둡니다.
- 서버는 10초 안에 올바른 토큰을 받지 못하면 시작하지 않습니다.
- DB를 열기 전에 개인 데이터 폴더 권한과 단일 프로세스 잠금을 확보합니다.
- 서버는 `127.0.0.1:0`으로 빈 포트를 직접 배정받고 준비 후 `FORGE_DESKTOP_READY:<port>` 한 줄을 출력합니다.
- 호스트는 `X-Forge-Session` 헤더로 `GET /api/desktop/ready`를 확인한 뒤 UI를 엽니다.
- 부모 파이프가 닫히면 Spring을 종료합니다. AI 요청을 자동 재실행하지 않습니다.

## 보호 범위

데스크톱 모드에서는 API 읽기·쓰기·다운로드·SSE에 모두 세션 토큰이 필요합니다.
공개로 허용하는 것은 UI 루트/고정 파일과 안전한 이름의 번들 자산 GET/HEAD뿐입니다.
나머지 경로도 기본 거절해 경로의 세미콜론 같은 변형으로 API 인증을 피하지 못하게 합니다.
Host/Origin/변경 헤더 검사도 유지하고 Vite 개발 Origin은 허용하지 않습니다.
CSP는 같은 출처의 스크립트/통신만 허용하며 외부 임베딩을 차단합니다.

토큰은 로그·명령 인자·URL·브라우저 영속 저장소에 넣지 않습니다.
같은 OS 계정이 이미 악성 프로세스에 장악된 상황까지 격리하는 보안 경계는 아닙니다.
데이터 자체의 암호화나 OS 키체인 기능은 별도입니다.

## 실제 코드

- `desktop/DesktopBootstrap`: stdin 인증, 잠금, 포트 강제, 준비 신호, 부모 종료 감시.
- `DesktopSession`: 길이 제한/시간 제한/상수 시간 토큰 대조.
- `DesktopDataLock`: POSIX 개인 권한, 최종 경로·잠금 파일 심볼릭 링크 거절, 중복 실행 방지.
- `LocalRequestFilter`: 토큰과 기존 요청 경계/CSP.
- `desktopTransport.ts`: 메모리에만 주입된 토큰을 같은 출처 API 헤더에 추가. 리다이렉트·외부 URL 차단.
- `fetchEventSource.ts`: 헤더가 필요한 SSE를 fetch 스트림으로 읽고 UTF-8/CRLF 조각을 처리. 개발 모드는 기존 EventSource 유지.
- `download.ts`: 인증 fetch 후 임시 Blob URL로 다운로드. 토큰을 다운로드 URL에 넣지 않음.

## 검증과 남은 작업

토큰 누락·오류, 실제 로컬 HTTP 준비/종료, 잠금 선점, 개발 모드 유지, API/SSE/다운로드 경계,
변형 경로 차단을 테스트합니다. 초기 대상 테스트 10개 통과 후 변형 경로 테스트를 추가했습니다.
인증된 프런트 전송을 통합했고 전체 UI 185개/백엔드 316개 통과, 실제 AI 1개 skip입니다.
네이티브 호스트·Java 런타임 동봉·Finder 설치 검증은 별도 통합 단계입니다.
설치 패키지, 서명·공증 완료로 표시하지 않습니다.
