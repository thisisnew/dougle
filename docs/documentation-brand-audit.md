# Dougle 문서·화면 명칭 점검

## 변경 범위

- 현재 안내의 제품명과 문서 제목은 Dougle로 통일합니다. README·설계도·개발 지침·인수인계·설치 안내의 이전 이름을 정리했습니다.
- 일반 문서/릴리스 탐색 링크는 `thisisnew/dougle`로 갱신했습니다. 설치 안내는 0.1.20 배포 링크를 사용합니다.
- `internal-search.md`의 이전 로고 화면을 새 Dougle 화면으로 교체하고, 로컬 의미 검색·분할·인용 출처·DB v25 설명을 반영했습니다.
- 현재 사용법의 대화·자료·AI 연결·Workspace·질문 기록·첨부 화면을 가상 자료로 다시 촬영했습니다. 예전 제품명이 보이는 캡처를 현재 화면처럼 재사용하지 않습니다.
- 삭제된 지식 편집/자료 메타데이터 UI와 과거 릴리스 캡처는 검증 기록 링크로 보존하고 현재 사용법에서 구분합니다. 과거 인증/검증 사실을 현재 성공으로 바꾸지 않습니다.

## 의도적으로 유지하는 이름

- `Knowledge Forge.app`, `Knowledge.Forge_*`, `knowledge-forge.jar`, `dev.knowledgeforge.desktop` 및 실제 데이터/백업/패키지 경로: 기존 설치·자료·인증·서명 호환 식별자입니다. 문서의 명령도 실제 경로와 일치해야 합니다.
- 구버전 업데이트의 `knowledge-forge` 다운로드 주소: 기존 앱의 URL 허용 목록과 리디렉션 호환을 유지합니다. 일반 제품 소개 이름과는 다릅니다.
- 과거 브랜드 생성 프롬프트·릴리스의 당시 검증 사실: 기록임을 명시하고 보존합니다. 현재 이름은 [Dougle](dougle-brand.md)입니다.

## GitHub 공개 화면 재점검

2026-10-25 소스·문서 변경을 `main`에 반영하고 GitHub API로 `internal-search.md`의 Dougle 이미지와 README 상단 작은 로고 제거를 확인했습니다. 과거 릴리스 제목의 이전 제품명도 Dougle로 정리하고, 구버전 앱 메뉴 안내는 특정 브랜드 대신 ‘앱 메뉴’로 표시합니다. 과거 캡처는 당시 화면 링크로 구분하며 새 화면으로 검증 사실을 바꾸지 않습니다. 배포 자산 이름·서명·기존 업데이트 주소는 변경하지 않았습니다.

이 문서를 포함한 Markdown 112개의 로컬 링크 대상 존재 검사에서 누락은 없었습니다. 최종 화면 캡처·설치 결과는 [수집·검색 작업 보고서](ingestion-retrieval-upgrade.md)에 기록합니다. 로컬 수정과 GitHub 반영은 구분하며, 커밋/푸시 전에는 공개 문서가 바뀌지 않습니다.
