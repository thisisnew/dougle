# AI 결과 비교 — 자동 덮어쓰기 없이 확인

**생성 당시 문서, 현재 문서, AI 최초 결과를 나란히 확인합니다.**
갱신 제안의 비교 단계입니다. 후속 [거절·재검토 이력](proposal-decisions.md)과 [전체 채택](proposal-acceptance.md)은 구현했습니다. [수동 부분 반영](proposal-merge.md)도 구현했습니다. 자동 병합은 하지 않습니다.

## 사용 방법

1. 지식 영역의 **AI 생성 작업**에서 완료된 작업을 찾습니다.
2. **원래 문서와 비교**를 누릅니다. 누르기 전에는 비교 자료를 조회하지 않습니다.
3. 생성 후 원래 문서가 편집됐다면 경고를 확인합니다. 바뀌거나 삭제된 근거도 표시합니다.
4. 필요하면 **현재 문서 열기**로 이동해 직접 초안을 편집합니다. 저장하면 새 버전이며 게시에는 다시 검토가 필요합니다.

비교 조회는 읽기 전용입니다. 문서 저장·게시·외부 AI 전송을 하지 않습니다. 별도로 여는 처리 기록에서는 거절·재검토 이유를 저장할 수 있습니다.
본문과 근거는 HTML 실행 없이 원문으로 표시합니다. 휴대폰 크기에서는 세 문서를 세로로 표시합니다.
조회 시점의 비교이므로 다른 창에서 변경했다면 **비교 새로고침**을 누르세요.

## 어떤 버전을 비교하나?

| 화면 | 실제 데이터 |
|---|---|
| 생성 당시 문서 | 작업의 sourceCardId + expectedVersion |
| 현재 문서 | 같은 카드의 조회 시점 최신 버전 |
| AI 최초 결과 | 작업의 resultCardId + v1 |

AI 결과 카드도 나중에 편집됐을 수 있습니다. 최초 결과와 편집된 결과를 혼동하지 않도록
여기서는 항상 v1을 보여주고 **AI 결과의 최신 문서 열기**를 따로 제공합니다.
근거 최신성은 조회 시점의 마지막 로컬 수집본과 비교한 값이며 생성 당시 상태 기록은 아닙니다.
버전이 같다고 사실이 검증됐거나 자동 반영해도 된다는 뜻은 아닙니다.

## API와 실제 구조

`GET /api/workspaces/{workspaceId}/generation-jobs/{jobId}/comparison`

응답은 `{base, current, generated}`이며 각각 기존 `Document {card,version}` 형식입니다.
`GenerationComparisonController` → `GenerationComparisonService` → 기존 작업/지식 저장 포트를 사용합니다.
한 읽기 트랜잭션에서 작업과 문서를 조회합니다. 비교 도입 시에는 v9 그대로였으며, 후속 처리 이력에서 v10 테이블을 추가했습니다.

- 404: 작업 없음, 다른 Workspace, 원래 카드 또는 결과 카드 삭제.
- 409: 완료되지 않은 작업 또는 결과 카드 ID 없음.
- 원본 **파일**만 삭제됐다면 보존된 근거로 비교할 수 있고 MISSING을 표시합니다.
- 지식 **카드**가 삭제됐다면 작업 이력에서 문서를 재생성하지 않습니다.

## 검증 범위

백엔드 전용 테스트 5개: 불변 기준/최초 결과 선택, 사람 편집·게시본 보존,
원본 파일 삭제 후 근거 보존, Workspace 격리·미완료 거절, 카드 삭제·읽기 전용 HTTP.
UI 신규 6개: 세 문서 표시·HTML 비실행, 편집/근거 경고, 조회 실패 복구,
문서 편집 중 이동 차단, 조회 취소, 명시적 비교 버튼 전에는 요청 없음.

첫 UI 실행에서 기존 `beforeEach(() => api.mockReset())`가 mock 함수를 반환해
Vitest의 정리 함수로 실행되는 문제가 드러났습니다. 반환하지 않는 블록으로 수정했습니다.
실제 AI 호출·브라우저 시각 QA·Mac 설치형 검증은 이번 범위에 포함하지 않습니다.

### 실행 결과 (2026-10-21, macOS Intel)

| 명령 | 결과 |
|---|---|
| `npm --prefix frontend test -- --maxWorkers=2` | 69개 통과 |
| `npm --prefix frontend run build` | TypeScript/Vite 빌드 성공 |
| `bash scripts/maven.sh clean verify` | 135개 통과, 실제 CLI opt-in 1개 skip, JAR 빌드 성공 |
| `node scripts/smoke.mjs` | 실제 JAR 실행·재시작·비교 불변성 검증 통과 |

Smoke는 가상 CLI 결과를 사용합니다. 재시작 후 사람 편집 v2와 AI 결과 카드의 후속 편집이 있어도
생성 당시 v1/현재 v2/AI 최초 v1을 조회하고 기존 게시본 v1이 유지되는지 확인했습니다.
100개 가상 파일 기준 시작 12,419ms, 재시작 15,869ms, 목록 p95 10.10ms, 검색 p95 28.38ms입니다.
이전 측정보다 시작 시간이 늘었으며 원인은 분리 측정하지 않았습니다. 단일 실행·소규모 자료 결과로 성능을 보장하지 않습니다.
원시 측정과 환경은 [성능 기록](performance-phase3-foundation.json)을 확인하세요.

## 다음 작업

거절·재검토 이력은 후속 구현했습니다. 전체 채택 이력도 구현했습니다. 동일 근거의 수동 부분 반영·재대조 저장도 구현했습니다. 근거 재연결·줄 단위 충돌 표시는 남아 있습니다.
현재는 세 문서 전체 비교이며 줄 단위 diff나 자동 충돌 해결은 아닙니다.
자동 폴링/Git 변경에 따른 갱신 제안 생성도 아직 없습니다.
