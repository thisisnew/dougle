# CLUE 0.1.12 — 폴더 연결·설정·브랜드

## 변경

- 자료 추가를 파일·폴더·웹 링크·GitHub 선택 하나로 통합하고 새 가상 폴더·별도 파일 추가 버튼을 제거했습니다. 기존 파일·폴더/API는 보존합니다.
- 복잡한 답변 관리 창 대신 제목·날짜 카드 그리드인 질문 기록을 제공합니다. 클릭하면 메인 대화로 이동하며 목록 조회로 AI를 호출하지 않습니다.
- 첫 Workspace 안내의 집 그림을 제거하고 제목·설명·시작 버튼만 남겼습니다.

- 로컬 폴더는 경로 입력 대신 Finder의 폴더 전용 선택기를 사용합니다. 파일·없는 폴더·링크는 서버에서도 등록을 거부합니다.
- 자동 갱신과 Workspace 관리를 설정 탭으로 옮겼습니다. 기존 잘못된 항목·원본·DB·인증은 자동 변경하지 않습니다.
- 캐릭터는 수트·흰 셔츠·줄무늬 넥타이, CLUE 워드마크는 영화 타이틀 느낌의 굵은 Condensed·인디고 그라데이션·입체 그림자로 변경했습니다.
- [사용·설계](folder-settings.md), [브랜드](clue-brand.md).

## 검증 진행

- 오류 안내는 좁은 카드 안에 브랜드/제목/설명/종료 안내를 정렬했습니다. 기존 실행기에서 상태 확인 1회 실패로 서비스를 종료하던 경로를 연속 3회 실패 후 종료로 바꿨습니다. 성공하면 실패 횟수를 초기화하고 프로세스 종료 감시는 즉시 유지합니다. AI 자동 재전송은 없습니다. 사용자 화면만으로 실제 시간 초과의 원인까지 확정할 수는 없습니다.
- Java 전체 392건 중 391건 통과·실제 AI opt-in 1건 제외. 최종 안내 문구 후 Collector/Source 통합 35건도 통과했습니다(중복 합산하지 않음).
- 초기 UI 회귀 1건은 제거된 ‘더 보기’ 경로를 기대하던 검사라 수정했습니다. 네이티브/Java/UI 동시 실행 중 여러 UI 대기 제한이 초과되어 병렬 부하를 줄여 재검사합니다. 앱 시간 제한·인증 검증을 완화해 테스트를 통과시키지 않습니다.

- 최종 UI **252건**과 TypeScript/Vite 빌드 통과. 선택 취소·종류 변경 시 경로 초기화·통합 파일 추가·폴더 전용 명령·설정 탭 삭제 확인·질문 그리드 선택/검색/오류/늦은 응답 차단을 검사했습니다.
- Rust **19건** 통과. 일시적 상태 확인 실패 후 복구·연속 3회 실패 기준 포함. 실제 Finder 조작 완료를 단위 테스트 결과로 주장하지 않습니다.
- JAR 빌드·가상 자료 통합 검사 통과. 100개 파일·순차 검색 p95 **38.99ms**, 실제 AI/대규모 동시 성능 아님. [측정](performance-phase3-foundation.json).
- 전체 목록 감사 351개 파일·103개 테스트/fixture 파일. 어휘 참조 목록이며 실행 커버리지 수치가 아닙니다.
- 집 그림 제거 후 App 회귀 10건과 화면 빌드를 다시 통과했습니다(전체 252건에 중복 합산하지 않음).
- 브라우저에서 가상 파일 업로드·가상 Codex 답변·질문 카드 선택 후 기존 답변 열기를 확인했습니다. 실제 외부 AI는 호출하지 않았습니다. 설정 화면 확인 중 테스트 서버 종료로 발생한 fetch 오류는 서버 종료와 구분해 기록합니다.
- Intel 네이티브 시작 창 검사·일시적인 백엔드 정지 후 복구·종료 검사가 통과했습니다. 양 CPU 네이티브 빌드를 마쳤습니다. Finder 선택기의 수동 자동화는 OS 메뉴 선택이 반영되지 않아 완료하지 못했으며, 실제 선택 완료를 주장하지 않습니다.
- 네이티브 양 CPU 빌드·브라우저·설치본·공개 배포는 진행 중입니다. 공개 업데이트는 아직 0.1.11입니다.

Apple 공증·ARM 실기기·실제 외부 AI 호출은 이번 검사 범위가 아닙니다.
