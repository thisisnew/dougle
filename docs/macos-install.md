## 최신 다운로드 — 0.1.40 Preview

[최신 설치 파일](https://github.com/thisisnew/dougle/releases/tag/v0.1.40-preview.1)에서 Apple Silicon(M 시리즈) Mac용 `Dougle_0.1.40_arm64.dmg`를 받으세요. Intel Mac은 지원하지 않습니다. 앱 이름은 `Dougle.app`입니다. 기존 폴더는 삭제하지 말고 동기화를 다시 누르세요. 코드 폴더의 build 산출물이 새 제외 기준에 반영됩니다. Jira·Confluence는 설정 → 플러그인에서 다시 연결해 새 인증 경로를 사용하세요. 실패했던 동일 파일도 다시 분석합니다. 아래 과거 버전·GitHub 인증 계획은 현재 사용법이 아닙니다.

- 자료 추가는 **파일·폴더·웹 링크**를 제공합니다. Confluence Cloud는 설정의 Jira · Confluence 플러그인을 연결하세요. GitHub 코드는 PC에 내려받아 폴더로 추가하세요. 기존 GitHub 수집본은 보존하지만 원격 동기화하지 않습니다. 업데이트 후 실패했던 폴더를 다시 동기화하세요. 문제 항목은 느낌표에서 확인할 수 있습니다.
- AI 연결에서 Claude/Codex를 선택하고 연결하세요. 지원하는 회사 계정 별칭이 하나이고 저장한 선택이 없으면 자동 적용합니다. 연결 실패 시 탐색 결과를 같은 화면에서 표시합니다. 도구를 선택하면 인증 확인 후 재시작 없이 적용하며, 로그인 필요 상태에서는 브라우저 로그인에 이어집니다. 인증 확인에 실패하면 기존 설정을 유지합니다. 고급 경로 입력은 제거했습니다. 복잡한 셸 함수는 임의 실행하지 않습니다. AI 로그인 없이도 자료 추가·검색 준비는 가능합니다. [지원하는 별칭과 제한](company-alias-connection.md).
- 검색 모델과 Java 런타임은 기본 포함됩니다. Claude Code는 별도 설치한 실행 도구를 사용합니다.
- Apple 공증이 없는 Preview입니다. 조직의 실행 보안 정책에 따라 차단될 수 있으며, 보안 설정을 임의로 해제하지 마세요.
- Apple Silicon 패키지 검사와 실제 회사 환경 검사는 구분합니다. 다른 Mac/회사 계정의 실제 성공을 보장하지 않습니다. 0.1.32 이상은 앱 업데이트로 설치할 수 있습니다. 업데이트를 확인하지 못하면 위 DMG를 사용하세요.

## 0.1.32 새 Mac 인수 기준 — 작업 중

검사 개수와 실제 사용 성공은 다르다. 아래 항목은 **배포본**에서 검증하며, 가상 계정/모의 응답/Intel 검사만으로 회사 계정·M5 통과를 표시하지 않는다. 통합 브라우저 OAuth는 GitHub App 등록·조직 승인 전까지 완료가 아니다. 공개 피드는 이름 변경 이전 앱과의 자동 업데이트 호환을 검증하기 전에는 승격하지 않는다.

### 설치·첫 시작
- Apple Silicon DMG: 마운트 → Applications 복사 → Finder 실행 → 첫 화면 표시.
- Apple Silicon DMG: Mach-O/Java/Codex/Git/모델 아키텍처 일치, ARM 실기기 실행은 별도.
- HOME이 비어 있고 PATH가 `/usr/bin:/bin`뿐인 경우에도 내장 Java·Git·Codex·검색 엔진으로 시작.
- 개발 PC의 Java·Node·Git·npm·CLI 인증 파일에 암묵적으로 기대지 않음.
- 읽기 전용 DMG 안에서 실행, 공백·한글 경로로 복사, 저장 공간 부족·권한 거부·손상 파일은 각각 구분.
- 검색 엔진이 준비되지 않으면 준비 중/오류를 표시하고 준비 전 질문을 검색 실패로 오인하지 않음.
- 종료 후 자식 프로세스 정리, 중복 실행 잠금, 재시작 후 자료 유지.

### AI 도구·회사 실행 방식
- Codex/Claude 각각 기본 실행 도구 존재·부재·실행 불가·잘못된 CPU·손상 파일.
- 서로 다른 사용자의 명령 이름, 절대 경로, 경로의 공백·한글, 심볼릭 링크 실행 파일.
- Finder PATH와 터미널 PATH 차이, `/usr/bin/env` 인터프리터, Homebrew 설치 위치.
- 상대 경로·옵션·셸 치환·세미콜론·줄바꿈 거부, 별칭은 실행 파일과 구분하여 안내.
- 경로 저장만으로 도구를 실행하지 않음, 명시적 신뢰 확인, revision 충돌, 재시작 후 적용.
- 로그인 성공·로그인 필요·상태 확인 실패·인증 명령 미지원·타임아웃을 구분.
- 회사 Google/SSO 로그인, 취소, 승인 거부, 만료, 재로그인, 브라우저 열기 실패.
- 인증 상태 확인을 모델 이용권·원격 추론 성공으로 표현하지 않음.
- AI 없이 파일/폴더/GitHub 수집과 기록 조회 가능, 질문에만 AI 연결 필요.

### GitHub 회사 저장소
- 공개/비공개 저장소, 인증 없음/저장됨/만료/다른 사용자/다른 조직.
- Fine-grained token의 선택 저장소와 Contents 읽기 권한, 조직 승인 대기·거부.
- 401 인증 오류, 403 SSO·권한·요청 제한, 404 주소 또는 비공개 권한, 429, 5xx.
- 공개 조회에 성공해도 다른 비공개 저장소 접근 성공으로 일반화하지 않음.
- 잘못된 호스트·사용자정보 URL·HTTP·다른 포트·fragment·다른 API 경로 거부.
- 인증된 요청의 리다이렉트 거부, HTTP/CLI 오류에 토큰 비노출.
- 토큰이 명령 인자·저장소 URL·`.git/config`·브라우저 localStorage에 남지 않음.
- Git 쓰기 명령·credential helper·hooks·시스템 Git 설정·TLS 검증 해제 금지.
- 인증 변경 후 재수집, 실패 시 이전 토큰/기존 수집 자료 유지, 연결 해제 후 로컬 자료 유지.
- 수집 중 취소·네트워크 끊김·기본 브랜치 변경, 부분 clone의 지연 blob도 같은 인증 사용.
- 동기화 성공 후 실제 코드 본문·파일명·한국어 개념으로 검색까지 확인.

### 이름·기존 자료 이전
- DMG 파일명·볼륨명·앱 이름·실행 파일·Info.plist·Spotlight 표시가 Dougle.
- Java 패키지·Maven 산출물·npm/Rust 패키지·리소스 JAR·새 DB·새 저장 경로 일치.
- 기존 앱 실행 중 이전 거부, 새/구 폴더 충돌 거부, 심볼릭 링크 원본 거부.
- 기존 폴더 전체를 원자적으로 이동하여 자료·인증 파일·검색 상태 보존.
- SQLite WAL checkpoint 성공 후 파일명 변경, 기존 데이터·스키마 보존, 반복 실행 멱등.
- 이전 제품명은 명시적인 이전 코드와 불변 과거 배포/검증 이력에만 허용.

### 용량·품질
- CPU별 JAR에서 다른 플랫폼의 native 라이브러리와 디버그 심볼만 제외.
- 유지한 클래스·native 바이너리·라이선스의 원본 바이트 보존.
- 임베딩/재순위 모델·토크나이저 해시 유지, CPU별 모델 파일 검증.
- 전체 Java 런타임을 유지하고 CPU별 JAR에서 실제 앱 시작·SQLite·업로드·PDF·검색·인증 실행. Java 모듈 축소는 새 환경에서 누락 의존성이 발견되어 적용하지 않는다.
- 잘못된 CPU·누락 native 라이브러리·미완성 출력이면 패키징 실패.
- 설치 앱 바이트와 다운로드 바이트를 따로 비교하며 압축률을 품질 향상으로 표현하지 않음.

각 항목의 실제 실행 결과는 새 배포 보고서에 기록한다. 체크리스트 작성이나 단위 테스트 통과를 실기기 인수로 대체하지 않는다.

## 설치

Apple 메뉴 → **이 Mac에 관하여**에서 칩/프로세서를 확인하세요.

| 내 Mac | 받을 파일 | 다운로드 |
|---|---|---|
| Intel 프로세서 | `Knowledge.Forge_0.1.20_x86_64.dmg` | [Mac 미리보기](https://github.com/thisisnew/dougle/releases/tag/v0.1.20-preview.1) |
| Apple M 시리즈 칩 | `Knowledge.Forge_0.1.20_arm64.dmg` | [Mac 미리보기](https://github.com/thisisnew/dougle/releases/tag/v0.1.20-preview.1) |

보통은 DMG만 받으면 됩니다. 무결성을 직접 확인하려면 해당 CPU용 `SHA256SUMS` 파일에서 DMG 행의 SHA-256을 `shasum -a 256 받은파일.dmg` 결과와 비교하세요. 체크섬에는 앱이 사용하는 업데이트 파일도 포함됩니다.
0.1.5부터 GitHub 수집 도구도 앱에 포함되어 별도 Git 설치가 필요 없습니다. 기존 자료의 저장 형식(v21)은 유지됩니다. [내장 Git](bundled-git.md) · [전체 E2E 검사](e2e-report.md).

1. 제공된 DMG와 SHA-256을 확인합니다. 모르는 사람이 다시 올린 파일은 사용하지 마세요.
2. DMG를 열고 Dougle 앱(`Knowledge Forge.app`)을 Applications로 복사합니다.
3. 복사한 앱을 엽니다. Java는 앱에 들어 있으므로 별도로 설치하지 않습니다.
4. 첫 체험은 가상 자료로 합니다. 실제 회사 자료는 회사의 허용 범위부터 확인하세요.

기존 설치가 있다면 **앱 종료 → 데이터 폴더 전체 백업 → 앱 교체** 순서입니다.
Intel/ARM 앱은 같은 데이터 위치를 사용하므로 동시에 실행하지 마세요. 다른 PC에서는 Source·CLI 절대 경로도 다시 확인합니다.

## 처음 할 일

1. Workspace를 만듭니다.
2. **자료** 탭의 **+**로 파일·폴더·웹 링크·GitHub를 추가합니다. 등록 직후 자동 동기화합니다.
3. **AI 연결**에서 제공자·모델을 고르고 연결합니다.
4. **대화**에서 질문을 전송합니다. 전송은 관련 자료를 선택한 AI에 보내는 동의이며 별도 승인 버튼은 없습니다. 답변 아래 인용 출처를 확인합니다.
5. **질문 기록**에서 이전 답변을 다시 읽거나 삭제합니다. 지식 문서를 별도로 만들 필요는 없습니다.

**AI 연결 → Codex → 연결**을 누르고, 로그인이 필요하면 안내에 동의한 뒤 **브라우저에서 로그인**을 누르세요. Codex 실행 도구는 앱에 들어 있습니다.
0.1.7은 앱 전용 로그인을 사용합니다. 이전 버전에서 로그인했더라도 한 번 새로 로그인하며 기존 Codex 인증을 복사하거나 변경하지 않습니다. [로그인·스트리밍 안내](codex-managed-login.md).
Claude 연결은 현재 별도로 설치된 호환 도구가 있어야 합니다. 기존 AI 대화 내용을 앱이 그대로 가져오는 것은 아닙니다.
로그인 동의와 자료 전송 승인은 별개입니다. 실제 계정의 로그인·답변 성공은 별도 확인이 필요하며 인증 확인만으로 요금제/이용 한도를 보장하지 않습니다. [AI 연결 안내](provider-connection.md).
이전에 직접 실행 경로를 설정했다면 그 설정이 우선합니다. **AI 연결 → 연결 도움말 → 기존 실행 경로 설정**에서 빈값으로 저장하고 앱을 다시 열면 동봉 도구를 사용합니다.
연결 전에도 자료 보관과 이전 답변 열람은 가능합니다. 기본 질문 입력은 연결 후 활성화됩니다.
GitHub 수집용 Git도 앱에 들어 있습니다. 자동 폴링은 Source별 기본 OFF이며 켠 경우 앱이 실행 중일 때만 동작합니다.

자세한 기능은 [쉬운 사용법](how-it-works.md), 문맥 이어 묻기는 [별도 안내](context-requests.md)를 보세요.

## 데이터와 백업

데이터는 보통 다음 폴더에 있습니다. 앱이나 원본 폴더 안이 아닙니다.

```text
~/Library/Application Support/dev.knowledgeforge.desktop
```

- **앱을 완전히 종료한 뒤** Finder의 이동 → 폴더로 이동에서 위 경로를 엽니다.
- 폴더 전체를 다른 위치에 복사합니다. DB 파일 하나만 복사하지 마세요.
- 0.1.7부터 전용 로그인 파일도 들어갈 수 있습니다. 백업을 공개하거나 지원 문의에 첨부하지 마세요. 다른 사람에게 인증 파일을 전달하지 않습니다.
- 복구할 때도 앱을 종료합니다. 현재 폴더를 먼저 다른 이름으로 보관한 뒤 백업 폴더를 복사합니다.
- 새 버전에서 연 데이터를 구버전 앱으로 열지 마세요. 현재 로컬 0.1.22 설치본 DB는 v28이며 역마이그레이션은 없습니다. 이전 0.1.20/v25 기록은 과거 범위입니다.
- 개발용 저장소의 `.data`는 자동으로 가져오지 않습니다. 실행 중 데이터 이동은 금지합니다.

앱 삭제는 Applications의 앱만 휴지통으로 옮깁니다. 데이터는 남겨 둡니다.
데이터까지 지우는 작업은 필요한 백업을 만든 뒤 사용자가 별도로 결정하세요.

## 문제가 생기면

- 시작 실패: 다른 Dougle 창을 닫고 저장 공간을 확인합니다.
- 서버 종료 안내: 앱을 닫았다 다시 엽니다. 이전 AI 요청을 자동 재전송하지 않습니다.
- 답변 중단: 창 닫기 대신 **답변 중단**을 누릅니다. 이미 외부로 보낸 내용은 회수할 수 없습니다.
- 오래된 근거: 새 동기화/검색 묶음을 준비합니다. 사람 편집 문서를 자동으로 덮어쓰지 않습니다.
