# 첫 사용자 체험 기준 — Mac 설치형

사용자 결정 (2026-10-21): 개발 서버 체험 대신 **설치형 앱이 준비된 뒤** 사용합니다.
2026-10-22: Intel Mac용 `.app`/`.dmg`와 Java 동봉을 구현했습니다. DMG 설치 복사본의 네이티브 UI 검증도 통과했습니다. [증거·한계](desktop-report.md). 아직 전체 체험 완료 기준을 모두 통과한 것은 아닙니다.

## 체험 준비 완료 조건

- Tauri 2 `.app`/`.dmg` 빌드, 대상 Mac 아키텍처 명시 (Intel/Apple Silicon을 혼동하지 않기).
- Java 런타임 포함: 사용자가 Java/Node/Maven을 별도로 설치하거나 터미널 서버를 실행하지 않아도 앱 실행.
- Java sidecar 시작·준비 확인·종료·충돌 복구, 포트 충돌 처리, 로컬 세션 인증 경계 검증.
- OS 앱 데이터 경로 사용, 앱 재시작 후 Workspace/자료/지식 복원, 업그레이드·백업/복원 검증.
- 가상 자료로 등록 → 수집/검색 → 지식 열람/편집 → 종료/재실행을 설치본에서 검증.
- 실제 AI 기능은 별도 로그인된 CLI가 필요함을 표시. 설치 진단과 생성 성공을 구분하고 승인 없는 전송 금지.
- 서명/공증 여부와 Gatekeeper 설치 제약을 명시. 서명·공증에는 배포 자격 증명이 필요.
- 설치 파일·체크섬·설치/삭제 설명서와 미구현 기능 목록 제공.

## 단계별 사용 범위

| 시점 | 가능한 범위 | 아직 구분해야 할 것 |
|---|---|---|
| 현재 웹/JAR | 자료·지식·게시, 근거 질문·SSE·문맥 선택·중단, 폴링·관계 검색 | 실제 외부 AI 최종 호환성 별도 |
| 현재 Intel Mac 0.1.1 | 위 기능의 앱/Java 동봉, CLI 설정, 설치 복사본 UI·업그레이드·백업 복원 검증 | 미공증, Finder/Gatekeeper 사용자 절차·다른 실물 Mac 별도 |
| 후속 배포 검증 | 실제 로그인 CLI·다른 Mac·정식 서명 | Apple Silicon·Windows 별도 |

기존 Phase별 인수 조건을 생략하지 않습니다. 먼저 작은 가상 자료로 체험하고,
