## 발견해서 고친 문제

- 과도한 Rust 병렬 작업으로 브라우저 관측이 시간 초과됐습니다. 패키지 빌드 작업 수 기본값을 2로 제한했습니다.
- Java의 읽기 전용 라이선스 캐시 덮어쓰기가 실패했습니다. 생성한 스테이징/캐시의 소유자 쓰기 권한만 보정했습니다.
- Tauri DMG의 Finder 창 꾸미기가 실패했습니다. Finder 자동화 없이 `hdiutil`로 DMG를 만듭니다.
- Desktop 하위 임시 복사본에 FinderInfo/File Provider 메타데이터가 붙어 서명 검사가 실패했습니다. OS 임시 폴더에서 생성하고, 생성본의 FinderInfo/ResourceFork만 정리한 뒤 서명을 재검사합니다. 사용자 앱·격리 속성·보안 설정은 변경하지 않습니다.
- 새 네이티브 테스트가 잘못된 조회 API를 사용했습니다. `/api/session`으로 수정했으며 종료 코드뿐 아니라 완료 경로를 확인합니다.
- 호스트 테스트의 포트 탐지가 호스트 이름 해석 때문에 실패해 `lsof -nP`로 수정했습니다. 중복 기동 검사는 초기 15초 제한에서 실패한 뒤 재검증을 통과했으며, 느린 기동도 제품의 60초 준비 제한에 맞춰 기다리도록 보강했습니다.

## 아직 확인하지 않은 것

- Finder에서 인터넷 다운로드 후 Gatekeeper 허용을 거치는 실제 사용자 설치.
- Developer ID 서명·공증, Apple Silicon, 다른 Mac에서의 재현.
- Finder의 CLI 경로 설정 UX, 실제 CLI 로그인/원격 생성 호환성.
- 설치형에서 모든 지식 편집·백업 복구 흐름을 사람처럼 클릭하는 전체 회귀.
- Source 자동 폴링·Git 네트워크 증분·관계 검색 등 남은 제품 기능.

설치 파일 생성과 전체 제품 완성을 혼동하지 않습니다.
