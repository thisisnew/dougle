# 0.1.4 — E2E 점검과 제공자별 모델 수정

## 변경

- Claude로 지식 화면을 새로 열 때 Codex 모델 설정이 섞이던 초기화 오류 수정.
- 별도 터미널 설치를 요구하던 안내와 모든 지식을 미검증으로 설명하던 상단 문구 수정.
- 격리된 브라우저 E2E 실행 도구와 네이티브 UI 실패 단계 진단 추가.
- DB v21, 백엔드 API, 업데이트 서명 키는 그대로 유지.

전체 사용자 흐름과 처음 실패한 검사도 [E2E 기록](e2e-report.md)에 구분했습니다.

## 검증과 설치 파일

- Maven clean verify: **366건 중 365 통과, 실제 외부 AI 1 제외**.
- UI **204 통과**, TypeScript/Vite 빌드 성공. 모델 복원 회귀 2개는 수정 전에 실패하는 것부터 확인했습니다.
- Rust **16 통과**, all-targets clippy 경고 없음.
- 동봉 Java/JAR의 인증 API 주 흐름·답변 SSE·지식·문맥·승인·취소·재시작 검사 통과. 설치본 0.1.3 전체 점검 후, 0.1.4로 이 주 흐름과 수정 UI를 다시 확인했습니다.
- CLI 경로 설정, 실제 예약 폴링, 관계 검색, 가상 로그인, v18→v21 자료 보존·종료 상태 백업 복원, 가상 앱 서명 업데이트 검사 통과.
- 0.1.4 Intel DMG의 실제 React Workspace/AI 버튼·한글·업로드/검색/게시·OFF 폴링 검사 통과.
- 창이 실제로 열린 뒤 크기를 검사하도록 테스트 순서를 고친 후 설치 복사본 UI 검사를 3회 연속 통과했습니다. 앱의 40px 검사·보안·시간 제한은 유지했습니다.
- 실제 0.1.4 네이티브 실행 파일을 격리 HOME·최소 PATH에서 실행해 동봉 Java·데이터 경로·중복 실행·종료·재시작을 통과했습니다. 단일 시작 측정은 9,791ms이며 일반 성능 보장이 아닙니다. [측정 원본](native-host-report.json).
- ARM DMG 설치 복사본·CPU·ad-hoc 서명 정적 검사 통과. 두 CPU 업데이트 압축의 공개 키/서명 버전·앱 버전·CPU·현재 JAR 일치 검사 통과.
- 실제 수정본 브라우저에서 Claude 기본값/저장한 모델과 Codex 저장한 모델을 각각 확인했습니다. 가상 AI는 별도 미게시 초안으로 생성되고 원래 문서는 남았습니다. 390px 폭에서 가로 넘침과 수집된 미처리 오류가 없었습니다.
- 코드/빌드 설정 **314개, 테스트·fixture 88개**의 목록·해시를 재생성했습니다. 파일 열거는 모든 실행 경로 커버리지가 아닙니다.
